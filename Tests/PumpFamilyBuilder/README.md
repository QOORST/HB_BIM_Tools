# 泵浦概念族群建置器（Revit 2024）

獨立試作，不修改 HB_BIM 主工具或既有 RevitMCP。輸入為 `Docs/FamilyAutomation/pump-sample-001.input.json`，限定 EF 型錄第 4 頁 TOS-EF-05／21 的平面配置。

## 執行

1. `dotnet build Tests/PumpFamilyBuilder/PumpFamilyBuilder.csproj -c Release`
2. 儲存並關閉既有 Revit 工作。
3. 執行 `Tests/PumpFamilyBuilder/Run-Prototype.ps1`。它建立本次專用的應用程式註冊檔，啟動 Revit 2024，並由一次性 Idling 回呼建族。
4. 查看 `artifacts/PumpFamilyBuilder/<RunName>/output` 的 `result.json` 或 `failure.txt`。外掛載入提示若阻止啟動，需先處理可見提示。
5. 完成後移除 `launch.json` 記錄的本次專用 `.addin`，不修改其他外掛。`run.request.txt` 在執行前即消耗，後续重開 Revit 不會重複建族。

每輪使用不同輸出目錄，不覆寫既有 RFA。不自動關閉使用者的 Revit 或文件。

## 幾何與參數

- 泵浦高度、泵體直徑、出口高度為類型參數，連動原生擠出及半徑標註。
- 導桿長度是實例參數；初始 1500 mm 明確屬試作假設。導桿概念外徑 42 mm 尚未確認管材標準。
- 導桿長度改變時，上固定架跟隨，泵浦與出口位置不變。
- `來源尺寸_*` 僅作原型錄追溯，不宣稱全部控制幾何。
- 初版平面定位固定；不支援把不同系列任意套入。主要支撐、連接段及把手為簡化幾何，未建螺栓、法蘭孔、內部零件。
- 管線接頭暫採污排水分類（Sanitary），位於向上法蘭面；這是試作系統選擇，正式專案需確認適合的分類。
- 名義 2 inch 接頭參數按 50.8 mm 表示，不代表管外徑或法蘭內徑，也未自動換為 DN50。
- 電氣接頭尚未建立；保留缺漏狀態，避免用馬達 kW 假裝電氣輸入功率。
- 馬力／略重等第一版追溯數值為帶單位名稱的 Number 參數；正式版需對接公司共用參數、GUID 及適當物理資料型別。
- 本版使用一般族群參數，未擅自建立公司共用參數 GUID。

## 執行時驗證

1. 两個類型出口高度與朝向。
2. 導桿長度 1000、2000 mm，確認高度連動及出口保持不動。
3. 泵浦高度 600 mm、直徑 180 mm，確認馬達幾何連動。
4. 出口高度改為 280 mm，確認接頭隨動。
5. 恢復原型錄與試作初始值，儲存並重新開啟 RFA。
6. 嘗試在新建給排水測試專案放置兩類型，建立接管並檢查實際連接關係，另存 QA RVT。

結果以執行輸出為準。編譯成功不等於 Revit 驗證通過；2025／2026 尚未測試。預覽匯出失敗及測試專案失敗分開記錄，不假稱通過。
