# 模組介面離線檢查

在儲存庫根目錄執行：

```powershell
dotnet run --project Tests/ModuleUi.Tests/ModuleUi.Tests.csproj -c Release -- artifacts/tool-ui-audit/modules
```

需 Windows 與 .NET 10 SDK。測試會在畫面外開啟介面，並將預覽 PNG 寫入指定資料夾。

驗證智慧圖例預覽與設定失效流程、自動標籤摘要、共用設定視窗的控制項生命週期、MEP 檢查的排出口選取往返流程，以及自動配管的坡度換算。圖例與標籤資料使用測試替身；房間裝修與管線等角視圖僅載入實際 XAML 檢查排版，未執行 Revit 事件處理。

此專案不驗證 Revit 實際點選、幾何運算、交易或模型寫入。部署後仍需在 Revit 驗證排出口點選／取消、圖例建立與更新、標籤放置，以及不同 DPI 的視窗操作。

自動標籤另涵蓋「連結內選取」的來源實例、選取數量、唯一識別去重、切換連結／文件清除清單、重新整理保留清單，以及暫存清單不寫入預設。加上 `-p:DefineConstants=REVIT2024` 可驗證 2024 的範圍選單分支；未指定時驗證 2022 分支。

Revit 驗收：指定連結後點選構件，Esc 保留原清單，完成後返回視窗；僅為已選構件中勾選的分類建立標籤。需測試同檔不同連結實例、重複執行略過既有標籤、來源刪除／卸載、切換視圖要求重新選取，以及預覽取消不保留標籤。選取清單限本次視窗，不隨「儲存預設」保存；管排模式仍使用原本的本機「目前選取」。
