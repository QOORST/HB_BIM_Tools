# 套管交易與標註回歸

執行 `./Tools/QA/SleeveTransactions/Run-Tests.ps1 -Repo <專案根目錄>`。
測試直接編譯專案 SleeveAnnotationGuard 與擷取的 ExecuteCreate；Revit API 使用模擬物件，不代表原生模型驗收。

覆蓋略過既有／更新模式下：成功提交、既有失效標註保持不變、原有效尺寸失效、穩定參照改變、標籤失聯、原套管刪除、交易提交拒絕、群組提交拒絕、寫入例外、回復例外。
既有失效不是豁免刪除或更換參照；套管身分、尺寸參照序列與標籤對象仍須保持。

指令層規則：只有確認本次交易群組已回復的 SleeveOperationRolledBackException 可以被處理後回傳 Result.Succeeded，目的是避免 Revit 再撤銷先前已提交的預設族群載入，不表示套管已建立。
未知例外或未確認回復仍回傳 Failed；WPF 禁止再執行並於關閉後交由 Revit 回復整個指令。
載入族群後取消設定或取消樓層確認，保留已載入族群，不建立套管。載入前取消選取仍是 Cancelled。

實機驗收：在模型副本分別開關略過既有套管；若再次失敗，記錄新版訊息中的尺寸／標籤 ID。連續開啟設定、取消、執行失敗後再開啟，確認同名族群不再重複升級。未完成此驗收前仍為測試版。
