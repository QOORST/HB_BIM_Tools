# HB_BIM Tools 圖示規劃

## 目前檢核結論

整體 Ribbon 圖示已具備一致方向，可維持目前的白底、細線、少量識別色風格。後續優化重點不建議一次全部重畫，而是補齊下列一致性規則。

1. Ribbon 圖示需由 `CreateIcons.ps1` 統一產生，避免手工 PNG 混入不同風格。
2. 開啟視窗的主工具需套用相同模組圖示作為 titlebar icon，避免出現 Revit 預設 icon 或各模組自帶舊圖。
3. 舊灰階 `_bw` 圖示僅保留相容，不再作為新按鈕指定圖示。
4. 同一工具組可共用母圖示，但主功能、設定、刪除、匯入、匯出需用明確輔助符號區分。

## 建議下一步

1. 建立共用視窗 icon helper，讓 WPF `Window.Icon` 與 WinForms `Form.Icon` 都能從 `Resources\Icons\<icon>_32.png` 載入。
2. 先套用在常開視窗：授權管理、自動標註、裝修工具、套管管理、MEP 檢查、族參數名稱修改、族群資料庫。
3. 清查未使用的歷史圖示，例如 `company_library`、`pipe_sleeve_bw`、`mep_rotate_bw`、`mep_rotate_settings_bw`，確認沒有舊版相容需求後再移除。

## 維護方式

新增或調整圖示時，先更新 `CreateIcons.ps1`，再執行腳本同步下列位置：

- `Resources\Icons`
- `Installer\Resources\Icons`

在 `App.cs` 中設定 Ribbon 圖示時，統一使用：

```csharp
SetButtonIcon(buttonData, "icon_name");
```

外部 DLL 按鈕使用：

```csharp
SetExternalButtonIcon(buttonData, "icon_name");
```

## 設計原則

- 尺寸：16x16 與 32x32 PNG。
- 背景：透明。
- 主線：深藍灰或模組主色。
- 識別色：每個圖示最多 1 到 2 個輔助色。
- 小尺寸優先：16px 必須仍可辨識主功能。
- 不使用 Revit/RVT 小圖示作為公司工具主 icon；Revit icon 適合表示檔案類型，不適合作為公司模組識別。
