# AR 裝修 - 更換裝修面顏色功能

## 📋 功能說明

這個功能允許您**選擇已創建的一般模型裝修面**，並**更換其材質顏色**，無需重新創建。

---

## 🎯 使用場景

### 適用情況：
- ✅ **一般模型模式**創建的裝修面
- ✅ 需要調整顏色以區分不同區域
- ✅ 需要統一修改多個裝修面的顏色

### 不適用情況：
- ❌ **牆/樓板類型模式**創建的裝修面（這些使用 Revit 本身的材質系統）

---

## 🚀 使用步驟

### 1. 執行命令
在 Revit 中執行 `CmdChangeFinishingColor` 命令

### 2. 選擇裝修面
- 點選要更換顏色的裝修面（可多選）
- 只能選擇**一般模型（DirectShape）**類型的裝修面
- 按 **ESC** 結束選擇

### 3. 選擇新材質
- 在彈出的對話框中選擇新的材質
- 材質列表按名稱排序
- 點擊「確定」應用更換

### 4. 完成
- 系統會自動更新所有選中裝修面的顏色
- 顯示成功更換的數量

---

## 💡 技術細節

### 更換顏色的機制

1. **更新共用參數**：
   - 更新「裝修材質」參數為新材質名稱

2. **更新視圖覆蓋**：
   - 使用 `VisualEffectsManager.SetFormworkMaterialAndColor`
   - 為所有視圖設定新的材質顏色
   - 支援灰色材質的顏色推斷（從材質名稱識別）

3. **支援的顏色推斷**：
   - 藍/蓝 → RGB(0, 112, 192)
   - 紅/红 → RGB(255, 0, 0)
   - 綠/绿 → RGB(0, 176, 80)
   - 黃/黄 → RGB(255, 192, 0)
   - 白 → RGB(255, 255, 255)
   - 黑 → RGB(0, 0, 0)

---

## 🔧 代碼結構

### 主要類別

1. **CmdChangeFinishingColor**
   - 主命令類別
   - 處理選擇和更換邏輯

2. **FinishingElementFilter**
   - 選擇過濾器
   - 只允許選擇有「裝修材質」參數的 DirectShape

3. **MaterialPickerDialog**
   - 材質選擇對話框
   - 顯示所有可用材質的列表

## 📊 與「面生面」功能的對比

| 特性 | 面生面 | 更換顏色 |
|------|--------|---------|
| **功能** | 創建新的裝修面 | 更換已有裝修面的顏色 |
| **操作對象** | 結構元素的面 | 已創建的裝修面 |
| **材質設定** | 創建時設定 | 創建後修改 |
| **適用模式** | 一般模型 / 牆樓板類型 | 僅一般模型 |
| **是否重建** | 是 | 否 |

---

## ⚠️ 注意事項

1. **只能更換一般模型的顏色**
   - 牆/樓板類型的裝修面使用 Revit 本身的材質系統
   - 如需更換，請修改牆/樓板類型的材質設定

2. **顏色在所有視圖中生效**
   - 更換後的顏色會在所有視圖中顯示
   - 包括平面圖、3D 視圖等

3. **材質參數會同步更新**
   - 「裝修材質」參數會更新為新材質名稱
   - 用於數量統計和報表
