# HB_BIM Tools 安裝與診斷指南

## 正式安裝

使用者端請使用正式安裝檔：

```text
HB_BIM_Tools_v*_Setup.exe
```

安裝前請先關閉 Revit。安裝程式會寫入對應年份的 Revit Addins 目錄、安裝必要 DLL/Resources、建立解除安裝資訊，並匯入 LAN 憑證。

## 開發端產生安裝檔

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\Installer\Build_Installer.ps1
```

輸出位置：

```text
Output\HB_BIM_Tools_v*_Setup.exe
```

## 安裝後檢查

```text
C:\ProgramData\Autodesk\Revit\Addins\2024\HB_BIM_Tools.addin
C:\ProgramData\Autodesk\Revit\Addins\2024\HB_BIM\
```

請依實際 Revit 年版替換 `2024`。

`HB_BIM` 資料夾至少應包含：

- `YD_RevitTools.LicenseManager.dll`
- 依賴 DLL
- `Resources\Icons`
- `Resources\Families`

## 診斷用手動檢查

手動複製只建議用於故障診斷，不建議作為正式部署方式。若必須檢查 `.addin`，內容應類似：

```xml
<?xml version="1.0" encoding="utf-8"?>
<RevitAddIns>
  <AddIn Type="Application">
    <Name>HB_BIM Tools</Name>
    <Assembly>C:\ProgramData\Autodesk\Revit\Addins\2024\HB_BIM\YD_RevitTools.LicenseManager.dll</Assembly>
    <FullClassName>YD_RevitTools.LicenseManager.App</FullClassName>
    <ClientId>B3F5D2D4-9392-4A9E-9C0D-A6F5DD93FAC7</ClientId>
    <VendorId>LAN</VendorId>
    <VendorDescription>LAN, HB_BIM Tools</VendorDescription>
  </AddIn>
</RevitAddIns>
```

## 常見問題

### Revit 顯示無法載入外掛

確認 `.addin` 的 Assembly 路徑是否存在，且 DLL 沒有被防毒或權限政策封鎖。

### 其他電腦顯示發佈者未知或簽章警告

請使用正式安裝檔重新安裝。正式安裝檔會匯入 LAN 憑證；手動複製 DLL 不會處理此步驟。

### 公司族庫無法使用

公司族庫需要內網路徑。未連內網的電腦可以正常載入外掛，但公司族庫功能可能無法取得內網資源。
