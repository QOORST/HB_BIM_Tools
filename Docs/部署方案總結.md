# HB_BIM Tools 部署方案總結

## 建議方式

使用正式安裝檔部署：

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\Installer\Build_Installer.ps1
```

建置完成後，將 `Output\HB_BIM_Tools_v*_Setup.exe` 提供給使用者端安裝。

## 為什麼不再維護手動部署包

舊式手動部署包只複製 DLL、Resources 與 `.addin`，容易漏掉以下項目：

- Windows 解除安裝資訊。
- LAN 自簽憑證匯入 `LocalMachine Root` 與 `TrustedPublisher`。
- 版本化 installer payload。
- 舊版 Addins 與使用者層 Addins 清理。
- DLL 與安裝檔簽章驗證流程。

因此使用者端安裝、更新與移除都應以正式安裝檔為準。

## 使用者端安裝流程

1. 關閉 Revit。
2. 執行最新版 `HB_BIM_Tools_v*_Setup.exe`。
3. 選擇要安裝的 Revit 版本。
4. 安裝完成後重新啟動 Revit。
5. 確認 Ribbon 出現 `HB_BIM Tools` 頁籤。

## 目標安裝位置

```text
C:\ProgramData\Autodesk\Revit\Addins\<版本>\HB_BIM\
C:\ProgramData\Autodesk\Revit\Addins\<版本>\HB_BIM_Tools.addin
```

主 DLL 目前仍維持組件名稱：

```text
YD_RevitTools.LicenseManager.dll
```

這是現階段保留的組件/命名空間相容名稱，顯示名稱與安裝識別已使用 `HB_BIM Tools` / `HB_BIM`。

## 故障診斷

若使用者端看不到頁籤，優先確認：

- 安裝時 Revit 是否已關閉。
- 對應 Revit 年版是否已勾選。
- `HB_BIM_Tools.addin` 是否存在於對應年份 Addins 資料夾。
- `HB_BIM` 資料夾內是否包含主 DLL、依賴 DLL、`Resources\Icons`、`Resources\Families`。
- 目標電腦是否信任 LAN 憑證。

除非正在做診斷，不建議手動複製 DLL 到使用者電腦。
