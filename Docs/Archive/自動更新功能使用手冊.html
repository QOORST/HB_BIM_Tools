📋 功能概述

HB_BIM Tools 現已支援自動更新功能，使用者無需手動下載安裝程式，可直接透過工具內建的更新功能檢查並安裝最新版本。

✨ 核心優勢：
  • 無需訪問網站或下載頁面
  • 一鍵完成版本檢查和更新
  • 自動下載並啟動安裝程式
  • 查看詳細的更新內容和發布資訊

✨ 功能特色

🚀

一鍵更新

點擊按鈕即可檢查、下載並安裝最新版本，全程自動化。

🔔

智能提醒

開啟「關於」對話框時自動檢查更新，發現新版本時顯示提醒。

📊

詳細資訊

顯示當前版本、最新版本、更新內容和發布日期。

🔐

安全可靠

從官方伺服器下載，支援 HTTPS 加密傳輸。

⚡

快速響應

10 秒內完成版本檢查，不影響正常工作流程。

📝

更新日誌

查看每個版本的新功能、改進和修復內容。

🚀 使用方式

方式 1：透過「檢查更新」按鈕

1在 Revit 中打開 HB_BIM Tools 標籤

2點擊 About 面板中的「檢查更新」按鈕

3等待檢查完成（約 5-10 秒）

4如有新版本，點擊「是」開始下載

5下載完成後，關閉 Revit

6安裝程式會自動啟動，按照提示完成安裝

7完成安裝後重新啟動 Revit

方式 2：透過「關於 HB_BIM」對話框

1點擊 About 面板中的「關於 HB_BIM」按鈕

2如有新版本，對話框會顯示提醒訊息

3點擊「檢查更新」連結

4按照提示完成更新

💡 小提示：
  • 建議在開始工作前檢查更新，確保使用最新功能
  • 更新前請儲存所有未儲存的工作
  • 安裝過程需要關閉 Revit，請提前規劃

🌐 伺服器配置

version.json 格式

更新伺服器需要提供一個 JSON 格式的版本資訊檔案：

{ "version": "2.3.0", "downloadUrl": "https://download.ydbim.com/HB_BIM_Tools_v2.3_Setup.exe", "releaseNotes": "新功能：\n• 新增管線避讓工具\n• 優化 COBie 匯出性能\n• 修復已知問題", "releaseDate": "2025-12-10T00:00:00Z", "isCritical": false, "minimumVersion": "2.0.0" }

欄位說明

欄位 類型 必填 說明
version 字串 ✅ 最新版本號（如 "2.3.0"）
downloadUrl 字串 ✅ 安裝程式下載連結（HTTPS）
releaseNotes 字串 ❌ 更新說明（支援 \n 換行）
releaseDate 日期時間 ❌ 發布日期（ISO 8601 格式）
isCritical 布林值 ❌ 是否為重要更新
minimumVersion 字串 ❌ 最低相容版本

部署選項

選項 1：自架 Web 伺服器

1準備 Web 伺服器（Apache / Nginx / IIS）

2配置 HTTPS 憑證

3部署檔案到伺服器

https://api.ydbim.com/ ├── updates/ │ ├── version.json ← 版本資訊 │ └── HB_BIM_Tools_v2.3_Setup.exe ← 安裝程式

選項 2：使用 GitHub Releases

1創建 GitHub Repository

2發布 Release（標籤：v2.3.0）

3上傳安裝程式作為 Release 附件

4修改 UpdateService.cs 中的 URL

⚠️ 重要提醒：
  • 必須使用 HTTPS 協定確保安全性
  • 確保伺服器有足夠的頻寬支援下載
  • 定期備份版本檔案和安裝程式
  • 測試更新流程後再正式發布

🔧 疑難排解

常見問題

問題 1：無法連線到更新伺服器

可能原因：
  • 網路連線問題
  • 防火牆阻擋
  • 伺服器維護中
  • URL 配置錯誤
解決方案：
  • 檢查網路連線狀態
  • 檢查防火牆設定，允許 HB_BIM Tools 連線
  • 稍後再試或聯繫技術支援
  • 手動下載安裝程式

問題 2：下載超時

可能原因：
  • 網路速度慢
  • 安裝程式檔案過大
  • 伺服器負載高
解決方案：
  • 重試下載
  • 使用更快的網路連線
  • 手動下載安裝程式

問題 3：安裝程式無法啟動

可能原因：
  • 權限不足
  • 防毒軟體阻擋
  • 檔案損壞
解決方案：
  • 以管理員身份執行 Revit
  • 暫時關閉防毒軟體
  • 重新下載安裝程式
  • 手動執行安裝程式（位於 %TEMP% 目錄）

問題 4：顯示「已是最新版本」但實際有新版本

可能原因：
  • 伺服器 version.json 未更新
  • 瀏覽器或系統快取
  • 版本號格式錯誤
解決方案：
  • 檢查伺服器上的 version.json 檔案
  • 清除系統 DNS 快取
  • 確認版本號格式正確（如 "2.3.0"）
