- App.cs 掃描到 43 組字面圖示鍵；86 個 16／32 px PNG 均存在、尺寸正確，並與已部署檔案相同。

- 圖示總覽：../../artifacts/ui-audit/icons.html；原始掃描資料：icons.json、commands.json，同目錄。

## 建議的介面基準

1. 共用中性色背景、藍色主要操作；綠／黃／紅保留給成功、提醒與錯誤狀態。
2. 視窗採「標題與說明 → 分組設定 → 結果訊息 → 底部操作」。主要操作位置一致。
3. 依行為命名：「套用設定」只儲存；「執行標註／建立套管」修改模型；「關閉／取消」依實際行为區分。
4. 距離欄位直接標示模型 mm 或紙面 mm，並說清楚量測起點、終點與方向。
5. 不把 WinForms 點數與 WPF DIP 字級直接當作不同視覺尺寸；以實際 DPI 與畫面驗收。
6. 每個功能至少驗證正常、無選取、錯誤輸入、取消、重複執行；涉及模型變更再驗證交易回復與復原。

1. 自動標註／貼標／接合：測試模型正式執行、取消、重複執行及復原。
2. 支管對齊／快速上下行／翻彎避讓：檢查位置、尺寸、配件連接與失敗回復。

4. 定位尺寸／樓層歸位：檢查基準、樓層，以及原有位置與連接是否符合功能承諾。
5. COBie／Data：以測試檔驗證欄位映射、空資料及匯入匯出。

每項需記錄 Revit 版本、模型情境、預期與實際結果；未實測者保留待驗證狀態。

## 自動標註實際介面初驗

- 使用 computer-use 成功讀取並切換 Revit 2024 的自動標註視窗，補充前述限制：MCP 本身沒有 UI 入口，但可透過 Windows 視窗工具檢查介面。
- 標註設定頁：專案設定已載入，軸線清單及底部操作可見；目前選用「對角線 1.2mm(整數」樣式、左側方向。此次未執行標註。
- 距離設定／軸線：示意順序為標頭、總尺寸、第一道；A=3、B=3 紙面 mm，1:300 換算提示各為 900 模型 mm，與公式一致。
- 軸線標頭：左端與上端勾選，右端與下端未勾；「全部勾選／全部取消勾選」與軸線清單「全選／全不選」均可見，主要操作切換為「套用標頭」。只確認呈現，未點選套用或驗證批次勾選行為。
- 介面改進候選：標頭頁留白較多；軸線清單僅顯示約五列，可考慮增加可視列數，減少捲動。列入集中調整，不立即部署。
