# 2024／2026 共用套管設定

設定 DTO 與 XML Store 已從 2024 WPF 視窗抽離，兩個版本共用 AppData/HB_BIM_Tools/PipeSleeveSettings.xml，不以跨文件 ElementId 儲存；依族群與類型顯示名稱還原。既有自訂 DN 列一併保留。

預設 DN25/32/40→50A，DN50/65→80A，DN80→100A，DN100→125A，DN125→150A，DN150→200A，DN200→250A。既有儲存對應優先；無存檔時匹配完整 A 類型名稱，重複或缺少者待指定。2024 與 2026 使用共用公稱尺寸表。

2026 提供共用穿牆／樓板族型、進階管徑對應、依管徑對應開關、模型範圍、編號／更新與儲存預設。移除實際直徑輸入與實測淨空檢核，不把 100A 當成內徑 100 mm。圓形套管不再按管徑加增加量覆寫套管直徑參數；矩形開孔仍沿用既有計算。啟用對應表時未找到精確 DN 對應即略過，取消鄰近尺寸降級。

2026 設定視窗列出已載入模型族型；公司族庫載入仍需既有族庫工作流程，預載族群流程尚未完整移植；穿梁示意圖已補於右側固定「穿梁複核參考」區。共有設定是同一台電腦、同一使用者範圍，不會自動同步其他電腦。

驗證：2024 API 編譯通過，149 項離線檢查通過，包括存檔覆蓋預設、完整族型名稱匹配與分頁版面。尚未取得 Revit 2026 API 或完成實機驗證，尚未部署。

待驗收：2024 儲存後 2026 還原、取消不建立套管、50A 等類型尺寸不被改写、缺少／重複族型處理、既有套管更新。

穿梁參考更新：以可縮放圖元呈現 2024 既有 2H、孔徑、梁深比例及孔距提示，並註明非結構核可。149 項離線檢查及 2024 編譯通過，一般／最小視窗預覽均已檢視；2026 實機驗證與部署未完成。
