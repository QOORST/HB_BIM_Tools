# 筏基 CAD 定位與自動標籤版面

## 第一版範圍

- 入口：MEP 工具 / 套管與開孔 / 筏基 CAD 定位。
- 平面視圖中選定 CAD 連結，手動點選中心與穿越方向。
- 通氣、連通、溢水用途；族型、參考樓層、TOP/BOP、專案座標基準高程、偏移、長度、數量及中心間距。
- TOP/BOP 以套管外緣定位，使用實際外徑，非 DN。
- 多支沿點選方向左側排列，每批獨立交易。Esc 保留已完成批次。
- 限非宿主式單樓層族；需兩端圓形接點、實際管外直徑及可寫入實例長度。
- 設定另存 RaftCadSleeve.xml，不共用 PipeSleeveSettings.xml。基準高程及樓層每次確認，不跨模型沿用。
- CAD 來源與建立座標使用 Extensible Storage；不要求既有族先加入共用參數。
- 管理清單納管，但不進入原管線更新、去重與編號流程。初始編號 RC-元素Id。

## 限制

- 非 CAD 圖塊自動辨識；點選位置由使用者負責確認屬於選定 CAD。
- 未自動擷取連結模型板底或大底完成面，未驗證宿主穿越。
- 未提供既有構件批次來源轉換、CAD 重定位更新及共用參數標籤綁定。
- CAD 移動可標示待確認；原檔內容重新載入不保證自動偵測。
- 初始狀態為待確認，不能解讀為施工、防水或結構驗收通過。

## 驗收清單

1. TOP / BOP 在正負高程，60.5 / 129.1 / 216.3 外徑均維持正確外緣。
2. 旋轉與偏移 CAD、旋轉平面、不同專案原點及族插入原點。
3. 兩支以上排列、間距不足拒絕、缺少接點與長度參數拒絕且回復該批。
4. Esc 取消當批不影響前批；原管線自動套管不可配對或刪除 CAD 構件。
5. CAD 刪除或移动後重新檢查；CAD 列不得執行管線更新。
6. 自動標籤：640 / 920 寬、100% / 150% / 200% DPI、進階展開、長族名、分類篩選、螢幕切換。
