# 模型管理檢查

## 定位與操作

獨立於施工圖樣板管理，供模型管理人員確認專案資料、命名及族群整理事項。沿用既有命令 ID 與授權鍵，Ribbon 名稱改為「模型管理檢查」。不以分數判定模型品質。

1. 選擇「專案資料」、「命名規則（選用）」或「族群與類型」。預設專案資料，開啟視窗不自動掃描。
2. 按「開始檢查」。一次只執行選定項目；切換項目或設定會清除舊結果。
3. 選取結果，下方查看原因及處理建議；適用的模型實例可定位。定位成功會關閉視窗，再由命令切換視圖或選取實例。
4. 不適用項目可填理由「本次略過」；勾選「顯示已略過」後可恢復檢查。
5. 如需保留結果，先匯出 Excel。報告包含所有結果及略過原因，不受畫面篩選影響。

命名設定不寫入模型；透過「前往名稱整理」帶入的檢查分類及命名規則可供整理後重新檢查使用。略過原因僅保留在當次檢查視窗；同一視窗重新檢查會沿用相同元素、相同規則與相同問題的略過原因，問題內容改變時需重新確認。

## 檢查範圍

| 項目 | 內容 | 判讀限制 |
| --- | --- | --- |
| 專案資料 | 專案名稱、編號、狀態、業主是否填寫；明細表是否能讀取及是否有可見欄位 | 空白資料為建議確認，需求依專案決定；不強制所有明細表都有數量欄位 |
| 命名規則 | 選填族群、視圖樣板、篩選器、材質前綴；選用預設名稱提醒 | 前綴預設留白，不強制公司名稱，不自動改名 |
| 族群與類型 | 超過 30 個類型的族群、同分類跨族群同名類型 | 都是整理提示，不能據此認定錯誤或刪除內容 |

結果狀態：需處理、建議確認、已略過。零結果僅表示本次啟用規則未發現問題，不代表模型已驗收。

專案資訊、材質、篩選器、視圖樣板或沒有放置實例的類型，定位會說明應從哪個 Revit 原生介面查看，並保留檢查視窗。模型不會被此工具修改。
