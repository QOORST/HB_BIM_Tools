# 連結模型定位尺寸

## 行為
- 標註對象來源與定位基準來源分開選擇；依連結實例 UniqueId 記憶，不按檔名合併。
- 本機維持框選；連結對象使用 LinkedElement 多選，限指定的一層直接連結，不支援巢狀連結。
- 管線支援自動梁面與手選基準；套管、設備、開孔族及自動辨識沿用自動梁面定位。
- 開孔族選單依標註來源文件建立，切換來源會清除舊族選項；來源卸載不回退至本機。
- 管段線、族幾何範圍、套管軸向及族基準方向轉為出圖模型座標。引用使用 CreateLinkReference，不複製來源物件。
- 尺寸建立於出圖文件，沿用原生參照有效性與尺寸值檢查；無有效參照時回復該組。
- 執行時唯讀檢查目前視圖與指定連結相關的失效尺寸，列出 ID；不自動重建，也不提供背景監控。
- 多選的是畫面可點選物件；未新增以視圖篩選全連結模型或跨多個對象連結的批次功能。

## 離線驗證
`Tools/QA/LinkedDimensions/Run-Tests.ps1 -Repo <repo>` 編譯實際輔助類別，搭配模擬 Revit API。
24 項檢查含平移、旋轉、鏡射、多實例、卸載、失效選取、去重與唯讀參照通知。
不代表已驗證 Revit 的連結尺寸參照接受度或整個自動配梁算法。

驗證旋轉/鏡射/平移的連結、同檔多實例、設備與套管中心參照、指定開孔族。
