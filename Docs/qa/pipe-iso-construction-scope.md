# 管路 ISO：施工、算量與加工交付範圍

需求更新：2026-09-28。使用者明確要求最終成果符合施工實務，具算量、加工用途。

本文件為後續實作與驗收基準；不是宣告目前已具備施工或加工交付能力。

## 交付目標

同一個出圖範圍產生可核對的施工圖、模型數量表、材料清單，並在接合規則足夠時產生切管表與組立資訊。PNG 是預覽，不能當成唯一交付。施工圖需有尺寸、高程、坡度、設備接口、管徑及配件識別，且圖表元件可互相追溯。

## 數量必須分開

| 資料 | 用途與定義 |
| --- | --- |
| 模型直管長度 | 依 Revit 曲線量測；供模型核對，不能直接當採購或切管長度 |
| 模型配件數量 | 元件去重，按型別、材料、各端口徑、角度與接合方式分組 |
| 加工切管長度 | 明確識別量測基準及端部處理，依廠牌／系列資料與接合規則換算；不可重複扣除模型已包含的配件長度 |
| 採購量 | 依定尺、包裝、備品及損耗規則換算；規則未設定時不臆測，也不假稱已最佳化排料 |

## 實作階段

### 1. 完整範圍與可信算量

- 以實體管路 Connector 關係建立圖結構，支援反向建模、分支、環路、未接端及設備邊界。
- 系統／選取範圍為一致的資料來源；3D 視圖、標籤、BOM 與匯出皆核對同一份元件集合。
- 不用距離接近冒充接通。不跨越設備進入其他系統。漏件、重複件、不支援元件與缺資料逐項列出。
- 元件識別使用文件與 UniqueId，品項碼獨立於圖面排序；圖上編號與材料表建立明確映射。
- 型式、材料規格、公稱徑／各端尺寸、角度、接合方式及數量分開存放；未指定材料不推測。

### 2. 可核對的施工出圖

- 加入尺寸、高程基準、坡度／坡向、設備編號／接管口、跨圖續接與必要方向標記。
- 支援指定圖框、比例、圖號、版次與圖表配置；保留人工整理空間。
- 支援更新既有成果，新增／刪除／改徑／移位可辨識，避免重跑增生及舊 CSV 被誤認為最新。
- 尺寸明確區分中心到中心、端面到端面及定位尺寸，不混稱切管長度。
- 出圖驗收需與實際模型逐件核對，並由使用者確認一份實務樣圖。

### 3. 有明確規則的加工交付

- 先確定管材、接合方式、接頭廠牌／系列與加工廠交付格式，再定義加工規則。
- 管段建立可追溯編號，輸出各端處理、材料規格、口徑、切管長度、數量與組立關係。
- 插入深度、牙接有效長度、溝槽端處理、焊口間隙等按實際適用規則處理，不使用通用固定扣長冒充廠商尺寸。
- 缺少必要端部規格、規則或幾何時，仍可輸出已驗證的模型數量，但該件加工長度須明確留空／標示待確認；不得以估值填入正式加工欄位。
- PCF 僅在指定下游軟體驗證成功後才能標示可交付。CSV 切管表與組立圖可獨立作為第一個加工交付，不以 PCF 作為唯一選項。

## 驗收門檻

1. 圖／表／範圍內元件集合一致；每件只計一次；所有排除與缺值有原因。
2. 直管、彎頭、異徑三通、立管、坡管、環路及設備端點案例完整覆蓋。
3. 元件數及未四捨五入長度與人工／Revit 明細表核對；輸出顯示精度與允差另明定。
4. 同一管徑不同材料／規格／接合方式不誤合併；各接頭口徑不遺失。
5. 紙面無裁切；尺寸基準、坡向、高程及編號可讀；圖表可互查。
6. 加工先用經確認的實例比對模型基準、規則扣補與實際切管長度；允差依專案及加工廠規則確認，不自行宣稱通用標準。
7. 改模重跑可更新成果且保留修訂關係，不能覆寫後失去可追溯性。
8. 2024／2026 分別完成建置與實機驗收；2026 未驗證前不列為支援。

## 使用者已確認的首批範圍

- 管路：消防鋼管。
- 接合方式：溝槽／牙接／焊接，依模型辨識。
- 加工廠、接收軟體、交付格式、接頭廠牌／系列：未定。
- 實作順序：先完成實體連通及一致算量、管段／品項編號，再補施工圖尺寸與接合資料，最後接入有來源與版本的加工規則。
- 模型辨識策略：優先明確參數及已確認型別對照；族名／型別名稱僅作候選線索，不能由「消防鋼管」或單一含糊關鍵字推定所有端部。逐端儲存接合方式與來源，允許同件異端接合；未知或衝突均列待確認。
- 第一個加工資料介面以可檢核的管段清單／CSV 規劃，格式待加工廠確認；目前不建立臆測的標準扣長庫，不承諾任意 PCF 接收端相容。

## 常用規格參考樣板（使用者要求先採常用規格）

將「桂格」按上下文理解為「規格」。先採可修改的消防鋼管參考樣板，不要求先選定加工廠；樣板是設計／估算參考，不覆寫模型既有材料或接頭規格，也不冒稱所有台灣工程均適用。

- 優先序：專案明確指定／已確認型別對照 → 模型明確參數 → 參考樣板候選 → 未判定。參考值需保留來源與狀態。
- 管材：ASTM A795/A795M 可作消防鋼管參考規格選項；模型若指定 CNS/JIS 或其他規格則保留，不自動視為等價。材質、外徑、壁厚系列、表面處理分欄，缺資料不由顏色推定。
- 溝槽：以 Victaulic OGS 官方資料作第一個具名參考來源，必須逐項指定接頭系列、實際外徑、滾槽／切槽，不能把品牌內不同系列互相套用。
- 牙接：明確區分 PT/BSPT 與 NPT；未辨識螺紋制式前不生成正式牙接切管扣補值。
- 焊接：區分實際彎頭角度、長／短半徑及管件端面；焊口間隙依已確認製作規則，不使用固定 45°、1.5D 代替模型資料。
- 不因管徑大小自動決定牙接／溝槽／焊接，不因「消防」字樣直接指定所有管件材料與壓力等級。
- 可先做模型算量及明確標為參考的加工試算；正式加工表只允許必要尺寸、接合及規則都齊備的品項，其他品項列缺值與原因。

## 全系統管路範圍擴充（使用者確認）

使用者要求「其餘系統管線一並列入」。最終產品不限定消防，納入下列機電管路。此處指 Revit Pipe 管路；不因「管線」一詞自行擴張為風管、電管及電纜架。

| 系統 | 應涵蓋的資料與出圖需求 |
| --- | --- |
| 消防 | 消防水、灑水等；接合方式、管材、閥件與設備端點 |
| 給水／熱水／回水 | 材料、保溫、設備口、閥件及不同端部接合 |
| 排水／污水／廢水／通氣／雨水 | 坡度、坡向、高程基準、清潔口、存水彎、異徑斜三通／Y 型配件 |
| 空調水 | 冰水、冷卻水、熱水及冷凝排水；供回水識別、保溫、設備與閥件 |
| 冷媒 | 液管／氣管、材料與管徑、保溫、設備端點及實際接合規則 |
| 燃氣／壓縮空氣／其他專案管路 | 先支援通用連通、圖面及模型算量；規格、接合與加工規則需獨立確認，不套用消防預設 |

### 設計原則

- 系統識別優先使用 Revit 系統分類、系統型別與專案對照；名稱關鍵字只作候選。支援未分類系統的明確選取與提示，不誤分類。
- 加工規則鍵值依「管材／標準、實際外徑與壁厚系列、配件廠牌系列、接合方式、端部型式」決定；系統名稱用於選擇候選樣板，不能單獨決定加工扣長。
- 納入鋼管、不鏽鋼管、銅管、PVC／CPVC、PP-R／PE 等材料類別的資料模型與擴充介面；實際接合規則可含溝槽、牙接、焊接、法蘭、壓接、承插膠合、熱熔等。不得因材料類別就宣稱各加工規則已完成或適用所有產品。
- 共用 Connector 連通、選取範圍、元件去重、圖表編號、模型算量、更新與修訂機制。
- 按系統選擇標註樣板：排水重坡度／高程，空調水重供回水／保溫，設備管路重接口；不為每種系統複製完整生成器。
- 出圖系統名稱、材料規格與接合方式分欄；各端接合可能不同。未知材料／配件保留並列待確認，不靜默忽略。
- 保溫、塗裝、支吊架等獨立列項；模型未建立者不自動冒充已建模數量。若後續需要估算，必須明列估算規則與來源。
- 全系統可共用模型算量；加工按規則成熟度逐類開放。缺規則的系統仍可輸出圖面與算量，不能產生偽精確的正式切管長度。

### 分批實作／驗收

1. 共用資料核心與全系統範圍／算量；沿用消防測試模型作第一個基準，但架構不綁消防。
2. 消防鋼管接合與施工圖；並列給水及排水樣本，驗證共用資料不依消防名稱硬編碼。
3. 給水／熱水、排水／通氣／雨水、空調水，各補標註及配件規則與代表性樣本。
4. 冷媒、燃氣、壓縮空氣及專案自訂系統，依原廠／專案規格逐類補加工規則並驗收。
