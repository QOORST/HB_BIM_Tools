## 第三輪：MEP 操作與結果

- 手動上下翻彎：補上交易提交結果檢查，非 Committed 不顯示完成。
- 手選基準的管排批次定位：全部尺寸建立失敗時回傳 Cancelled，不再回傳 Succeeded；有成功建立的批次保留成功結果與失敗明細。
- 批次支管對齊：全部支管失敗時明確顯示「未完成任何支管對齊」，並回傳 Cancelled；部分成功保留現有成功變更與錯誤明細。
- 共用 MEP 設定視窗主色統一藍色；接點生成管的主操作依模式顯示「儲存設定／建立管段」、樓層歸位顯示「預覽歸位」、定位尺寸設定顯示「套用設定」。
- 樓層歸位：沒有可處理管段時提前提示，移除面向使用者的 V1 版本字樣。
- 接點生成管原有連接／端點驗證與成功提交檢查；樓層歸位原有管段位置／坡度／連接／目標樓層檢查；本輪保留幾何處理邏輯。
- Revit 2024 編譯 0 錯誤、6 個既有 API 過時警告，diff 空白檢查通過。本輪未新增模擬幾何測試，未在模型中執行翻彎或改動連接器，實際管件配置與全部／部分失敗情境待集中部署後驗收。
