# 自動標註 Revit 實測矩陣

狀態：待 Revit 內人工驗收。本機編譯與離線測試不代表實際模型通過。

測試環境：先 Revit 2024；記錄專案、視圖、比例、族名稱與版本。使用測試模型，操作前保留副本。

| 項目 | 操作 | 驗收條件 | 狀態 |
|---|---|---|---|
| 柱自動 | 結構柱／建築柱，各測左右與前後組合 | 參考面與標註側正確；無重複標註 | 待測 |
| 柱手動 | 點選放置側，再測 Esc 取消 | 側別正確；取消不新增標註且視窗恢復 | 待測 |
| 梁 | 平行梁、不同方向梁、不同族 | 梁寬與間距正確；不跨不相容方向串接 | 待測 |
| 軸線 | 水平／垂直／斜向平行直線，各測生成側 | 第一道與外框位置正確；不混合非平行組 | 待測 |
| 比例 | 1:50、1:100，軸線紙面距離 10 mm | 模型距離分別 500、1000 mm | 待測 |
| 型式 | 切換兩種線性標註型式 | 新標註使用選定型式 | 待測 |
| 標頭 | 左右上下單端、混合、全部勾選、全部取消 | 僅所選軸線標頭改變；全取消隱藏兩端 | 待測 |
| 反向／旋轉 | 反向繪製軸線、旋轉平面視圖 | 標頭方向按視圖左右上下判定 | 待測 |
| 記憶 | 套用全隱藏後關閉重開，再重啟 Revit | 保留四端全不勾；標註距離／型式不被覆寫 | 待測 |
| 專案隔離 | A、B 專案設定不同標頭，再切換專案 | 使用各自設定；不沿用另一專案標頭設定 | 待測 |
| 重新整理 | 修改未套用的標頭設定後重新整理同專案 | 保留視窗中尚未套用的四端設定 | 待測 |
| 空選取 | 清空軸線選取後套用 | 提示至少一條軸線，不更動模型 | 待測 |
| 重複執行 | 同設定連續執行柱／梁／軸線 | 檢查重複數與略過結果，記錄任何重複生成 | 待測 |
| 提交失敗 | 測試模型中觸發 Revit 交易失敗 | 不顯示已建立成功，不儲存失敗操作設定 | 待測 |
| 設定寫入失敗 | 隔離測試帳號中模擬設定檔不可寫 | 模型提交成功仍如實回報，另提示記憶未儲存 | 待測 |
| 不支援條件 | 曲線軸線、曲梁、連結模型、非平面標頭操作 | 不誤改模型；記錄略過或錯誤訊息 | 待測 |

每筆結果記錄：建立前後數量、實際距離、Revit 訊息與截圖。提交失敗情境須在可拋棄測試模型操作。
