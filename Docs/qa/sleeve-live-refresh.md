# 套管管理自動檢查（2026-09-22）

## 行為
- 「重新檢查」只重新讀取清單，不呼叫編號整理，不建立模型交易。
- 編號整理改為獨立「整理編號」按鈕，確認後才執行原整理流程。
- 管理視窗存續時訂閱 DocumentChanged；同文件任何已提交變更（包含復原／重做）標記清單待檢查。不在事件內掃描或寫入模型。
- Idling 檢查目前視圖切換及待檢查標記。最後一次變更至少經過 0.75 秒且無管理動作排隊、無可修改交易時，再讀取清單。
- 不保證固定 0.75 秒內完成；等待 Revit 閒置。全清單唯讀重查，不是增量檢查。大型模型耗時需原生測試。
- 執行管理更新／預覽期间，busy 防止閒置刷新重入。成功讀取後清除待檢查狀態，避免工具自身交易觸發重複刷新。
- 保留現有篩選、搜尋、選取 ID 及捲動位置（超過新筆數時夾限）。
- 自動刷新失敗只在狀態列提示，保留清單等待重新檢查或下一次變更，不反覆彈出錯誤視窗。
- 關閉視窗、文件失效或切換文件，在 Revit API context 解除 Idling／DocumentChanged 並釋放 ExternalEvent。
- 此次未重做管理清單／差異預覽的資訊架構。

## 驗證
- 2024／2026 Release x64 編譯：0 錯誤，6／27 項既有警告。
- 擷取實際 handler 執行 18 項 mock API 測試：跨文件忽略、延遲與合併、純讀取手動刷新、視圖切換、可修改交易暫緩、排隊動作暫緩、刷新失敗不重試轟炸、手動重試、編號整理獨立、清理冪等及切換文件關閉。
- 尚未部署／更新安裝檔；未進行 Revit 原生測試。

## 原生驗收
1. 開啟管理後移動來源管線：閒置後清單應反映變更；模型不得因刷新而移動、改號或產生新交易。
2. 連續移動、刪除、復原、重做：事件合併且不漏最後現況。
3. 切換視圖：管理範圍與清單更新；切換文件：舊管理視窗關閉。
4. 「重新檢查」前後編號相同；「整理編號」取消不寫入。
5. 更新預覽開啟時不重入刷新；關閉管理再開啟無重複訂閱或 API context 例外。
6. 大型模型測試刷新耗時、捲動與篩選保留，必要時再增加增量篩選。
