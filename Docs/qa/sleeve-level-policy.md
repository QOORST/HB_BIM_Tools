# 套管樓層規則修正（2026-09-22）

## 行為
- 自動套管主頁選擇「依來源管線樓層」或「指定樓層」。不依幾何高度猜測最近樓層。
- 新增套管採本次規則；跨樓層來源依其來源樓層分組，建立前顯示來源構件數量確認。
- 規則以目前視圖 Extensible Storage 記憶，模型儲存後才會隨 RVT 保存。不是全專案、棟別或自動區域辨識。
- 舊全專案 GL 設定不自動遷移；首次進入新介面預設來源樓層。筏基使用者需明確選擇 GL。
- 規則在成功建立、更新或略過既有套管的交易內保存；取消或交易失敗不保存。介面的「儲存預設」仍只保存一般尺寸設定。
- 管理更新及建立入口中的既有套管更新，都保留原約束樓層，以該樓層計算立面高程。更新仍可依來源變更位置與尺寸。
- 缺少有效約束樓層時拒絕更新，要求使用獨立樓層歸位功能。歸位原有幾何保護未修改。
- 管理清單不再以全專案 GL 是否指定或相符判斷異常；其他幾何及來源檢核保留。
- CAD 無來源套管只接受明確指定的樓層，可帶入目前視圖的指定樓層；無指定時留白，不默選最低樓層。成功建立後記憶同一視圖的指定樓層，後續自動套管主頁也會顯示此設定。
- 樓層確認是來源構件分組，不是穿越分析預覽，也不宣稱新增／更新数量的完整計畫。

## Revit 必測
1. 2F/3F 管線混合新增：各依來源樓層，確認摘要分組正確。
2. 筏基不同深度管線，指定 GL：位置不因樓層設定改變，偏移依 GL 計算。
3. 同模型另一視圖與另一模型不繼承該視圖設定；原視圖重新開啟保留選擇。
4. 刪除已記憶的指定樓層：顯示失效項目，執行前阻擋，不降級成來源／最近樓層。
5. 更新不同樓層既有套管：原 ID、約束樓層及標註參考保留；來源位置變更仍依更新流程同步。
6. 沒有專案 GL 的一般樓層不再出現「尚未指定 GL 約束樓層」。
7. CAD 首次未指定樓層不能開始；選擇並成功建立後，同視圖自動套管顯示指定樓層。
8. 取消確認不建立套管；交易失敗不保存新視圖規則。
9. 獨立樓層歸位維持位置、方向、尺寸、接點及相依標註；任一驗證失敗整批回復。
