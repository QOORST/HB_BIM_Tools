## 尺寸文字整理第二階段：DC3D 與跨鏈檢查（待部署、未實機驗證）

- DC3D 暫時線框：綠色為估算文字範圍，紅色為仍有碰撞的範圍；不是填色區域。
- 成功處理的選取尺寸鏈投影到共同視圖平面，以保守矩形檢查跨鏈碰撞；斜向文字可能有誤報。僅提示跨鏈衝突，尚未自動解決。
- 預覽沿用實際文字位置交易；否／關閉回復全部，是合併為單次可復原操作。對話框開啟期間不能操作視圖縮放。
- DC3D 只註冊於本次命令期間、只繪製原文件與原視圖，退出時移除自身註冊，保留其他外掛的啟用清單。
- 繪圖失敗或尚未收到 RenderScene 時顯示降級提示，不宣稱色框成功顯示。
- 未涵蓋未選取尺寸、略過尺寸、模型線條、標籤或文字精確外框。
- 最終 Revit 2024 編譯：0 錯誤、6 項既有警告；離線 139 項通過。DC3D 畫面與交易還原仍須 Revit 實測。

- [ ] 驗證確認、取消及异常退出後色框消失，其他 DC3D 外掛正常。
- [ ] 驗證同鏈排列及跨鏈衝突計數、取消精確還原與保留後單次復原。

## 尺寸文字整理第一階段（待部署與實機驗證）

- 入口：標註工具 → 尺寸文字整理；選取目前視圖的直線連續尺寸。
- 紙面淨間距預設 0.8 mm、每層偏移 5 mm；只在同一尺寸鏈估算文字矩形碰撞，向兩側最多各兩層排列。
- 正常文字保留；包含前後綴、上下文字及覆寫文字的長度估算。不是 Revit 真實文字邊界，須目視確認。
- 不可調整段落導致整條尺寸略過；逐條子交易隔離失敗。
- 原生交易預覽：否／關閉還原全部；是保留，後續可用 Revit 復原。尚未加入 DC3D 色塊、跨鏈或模型線條避讓，也未自動串接自動標註。

## MEP 工具列分組（程式完成，待部署）

使用者確認：只記住本次 Revit 開啟期間，設定不取代主按鈕。下拉清單維持固定順序，設定置於底部並以分隔線區隔。定位尺寸與接點生成管固定執行首項；快速上下行記住最近點選的上行／下行，設定結束回到 Revit 閒置時還原該方向。其他多操作群組使用原生最近使用同步。未新增跨重啟記憶；取消執行命令仍記住該次點選方向。

| 群組 | 下拉功能（固定順序） | 合併理由 |
| --- | --- | --- |
| 支管對齊 | 支管對齊、批次對齊 | 相同工作、不同操作數量 |
| 避讓翻彎 | 管線避讓、手動翻彎 | 既有中段路徑調整 |
| 快速上下行 | 快速上行、快速下行、上下行設定 | 末端延伸，與中段避讓分開 |
| 套管與開孔 | 自動套管、套管管理、分隔線、建築開孔 | 穿越需求與後續建築開孔流程 |
| 定位尺寸 | 管線定位尺寸、定位尺寸設定 | 執行與設定合併 |
| 接點生成管 | 接點生成管、生成管設定 | 保留原分組，主按鈕固定生成管 |
| 樓層歸位 | 獨立按鈕 | 參考樓層調整，不併入幾何生成 |

- 正式顯示項目由 10 個主按鈕縮為 7 個，15 個命令路由全部保留；未重新公開舊版隱藏工具。
- Revit 2024 Release 編譯 0 錯誤、6 個既有警告；原分組修改已核對全部 15 個命令保留。設定排除修正後再編譯通過，兩個執行／設定群組固定首項；快速上下行以命令入口記住方向、Idling 還原，關閉外掛時解除事件訂閱。
- 部署後驗收：快速下行 → 取消 → 開啟設定 → 儲存或取消 → 主按鈕仍為快速下行；快速上行同樣驗證。定位與生成管的設定無論儲存或取消，主按鈕維持執行功能。其他多操作群組點第二項後主按鈕應同步，重開 Revit 回到預設首項。原生快速上下行在設定執行中可能暫顯設定圖示，回到閒置後才還原；實機時序尚待驗證。
