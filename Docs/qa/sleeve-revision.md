# 套管穩定編號與版本差量

日期：2026-10-04。此階段處理市場比較後優先建議的「穩定編號＋版本差量」。施工樓層判定、核准流程、保溫／防火／防水尺寸規則及新版 Revit 移植仍屬後續工作。

## 建議操作：單一發圖視窗

開啟「套管管理 → 發圖作業」。此入口將原本分散的操作整合在同一個視窗：

1. 選擇表格類型、約束樓層、區域與圖紙；圖紙留在「只建立／更新明細表」時不自動放圖。
2. 在「1 檢查／統計設定」頁籤檢查套管，使用下拉選單設定納入、排除或作廢。原本依來源自動判斷的項目顯示自動納入／自動排除；不修改就保留原規則。排除項目也會顯示，方便恢復納入。
3. 若要管理手動套管，先在 Revit 選取，再勾選視窗內的明確納入選項；仍可逐支改為排除或作廢。
4. 切至「2 數量表預覽」核對支數；下拉選單的變更會即時反映在預覽，尚未寫入模型。
5. 輸入「3 發圖基準名稱」，例如 `A棟_R01_發圖`，按「補號、上圖並存基準」。未選圖紙時按鈕為「建立表格並存基準」。
6. 完成後儲存 RVT。後續比對仍使用「更多 → 版本基準／差量圖表」。

表格依所選樓層／區域篩選；保存的是整案本機套管基準，並補齊整案納入套管的編號。基準名稱必填且不能重複。待確認數量會明示，發圖作業不等於施工核准。

取消視窗會捨棄草稿。統計設定、手動納入、補號、表格、上圖與基準保存共用一個交易群組；其中一步失敗即回復整組，完成後可一次 Undo／Redo。失敗時視窗保留所填設定，供修正後重試。

區域目前仍由實例參數指定；本輪新增的是統計設定下拉選單，尚未改為自動施工樓層判定。

## 個別操作入口

1. 開啟套管管理 → 更多 → 套管數量表／放入圖紙，確認管理範圍；手動族群需明確納入。
2. 建表會保留原有編號並補齊範圍內空號。亦可由更多 → 補齊編號處理目前視圖內自動套管。
3. 發圖前，開啟更多 → 版本基準／差量圖表，輸入例如「A棟 R01 發圖」，按「補編號並儲存基準」。此動作會補齊整案納入套管的編號，將基準存入 RVT；請存檔保留。
4. 模型修改後選取基準並重新比對。可匯出 CSV，或建立固定的差量製圖視圖。
5. 單頁差量可直接置中放入選定圖紙；超出圖紙或覆蓋既有視圖／明細表時整筆回復。多頁差量先選「僅建立製圖視圖」，再逐頁拖曳配置。
6. 發新版前另存新名稱基準。建立新基準不覆寫舊版；差量圖表不隨後續模型變更更新，需重新建立新圖表。

## 編號保護

- 台帳以 Revit `UniqueId` 記錄號碼所有者，跨目前視圖保留模型內已使用的 `PS-` 號碼。
- 既有自訂編號保留；`PS-001` 與 `PS-1` 視為同號，大小寫不構成新號。
- 建立流程明確傳入本次新增構件；族群帶入的預設編號（例如 `1`）不視為已發出的舊號，新構件取得新的 `PS-` 編號。真正既有的重號仍保留衝突檢查，不依號碼外觀猜測新舊。
- 可寫入的實例參數「套管編號／編號／Sleeve Number」同步正式編號，避免標籤殘留族群預設值；一般門窗的同名自訂編號不納入套管衝突判斷。
- 台帳建立後，即使最大號構件刪除，新套管仍接續補號。首次使用前已刪除且未記錄的歷史編號無法回推。
- 已登記原件的副本在補號／建表時取得新號；空白的已登記原件恢復原號。手動複製後至執行補號前，Revit 可能暫時顯示相同編號。
- 首次接管模型時，若重號無法判定原件，或已登記構件被手動改成他人號碼，取消操作並要求排除衝突，不任意重排既有號碼。
- 編號與台帳同一交易提交／回復；工作共用的多人並行編號尚未驗證，不能宣稱跨本機副本完全避免競號。

## 管線移動後更新

- 移動來源管線後，在套管管理選取原套管，按「更新」，確認預覽後執行；自動檢查只重新檢查清單，不會自行搬動套管。
- 更新逐支配對完整實體穿越點；其他構件僅碰到外包框或未完整穿越，不再阻擋已有唯一有效配對的套管。
- 來源一致且舊套管中心仍位於同一宿主實體內時，可處理超過原鄰近距離的移動。配對不唯一、管線不再穿越、宿主已移離等無法確認情況仍保留原件並停止，不放大搜尋半徑猜測配對。
- 更新後核對實體中心、永久識別碼、約束樓層與既有標註；失敗則回復。無接點族群的明顯位移顯示「需更新」，位置對齊後仍標示淨空「待確認」，不宣稱補好接點。
- 建立視窗以 Revit 為父視窗；確認樓層後回到前景，顯示管線／穿越點處理進度，執行期間停用重複操作。完成與錯誤訊息歸屬套管視窗。

## 套管方向與斜管淨空

- 穿牆、穿梁、穿樓板統一垂直於實際穿越面；斜樓板依斜面法向，不強制套用世界 Z 軸。管線坡度不直接決定套管方向。
- 以完整實體穿越的入口、出口確認平行面，再沿法向重新量測實體厚度與中心；連結構件先在連結座標計算，再轉換一次至本機。
- 曲面、角點歧義或入口／出口不平行時，無法保證同時垂直兩面，保留原件並要求確認。
- 有兩個端點接頭時，以接頭中心連線作為實際套管軸向；修正小角度傾斜後再次核對方向，旋轉失敗回復。無接頭族群仍使用族群方向，淨空維持待確認。
- 若一般旋轉被 MEP 族群忽略，先回復該次操作，再以兩次原位鏡射完成等效旋轉，核對永久識別碼與原鏡射狀態均保留；此替代方式不處理已連接到 MEP 網路的族群。
- 斜管不再一律顯示待確認：圓管依端面偏心、外徑、斜切橢圓包絡及有效內徑保守計算。此檢查假設套管為直線等內徑，不代表防火或止水核准。
- 既有套管須在管理視窗選取後執行「更新」及確認；更新外掛本身不會改動已儲存模型。
- 2026-10-04 驗證：95 項離線、64 項 Revit 2024 原生檢查通過；包含實際斜樓板與旋轉梁體實體。連結部分驗證座標轉換，尚非完整載入 RVT 連結的案例。Revit 2022 通過編譯，原生執行尚未驗證。紀錄：`artifacts/sleeve-axis-fix/validation.json`。

## 差量定義

- 範圍：本機整案已辨識／登記的套管，含排除及作廢；不受目前視圖裁剪影響，不納入連結模型中的套管。
- 以永久識別碼比對；刪除再建即為刪除＋新增，即使編號或位置相同。
- 比對項目：新增、刪除、作廢、排除、恢復納入、失去辨識、編號、位置、方向、尺寸、族型、材質、約束樓層、區域、系統、穿越構件文字及檢核狀態。穿越構件目前沿用既有資料文字，非獨立宿主幾何追蹤。
- 位移依三維距離超過 0.5 mm 判定；方向比較族群變換矩陣；XYZ 為 Revit 內部原點座標。尺寸沿用數量表的正規化欄位。
- 支數增減 = 目前納入值 − 基準納入值，每個值為 0 或 1。尺寸變更本身為 0 支，基準與目前規格仍各自完整列出。
- 已作廢構件再刪除不重複扣量。每次比對核對「差量合計 = 目前納入總數 − 基準納入總數」。
- 差量中的「恢復納入」只代表統計設定，不代表施工核准；待確認套管仍可計入模型量。
- CSV 為含 BOM 的 UTF-8；文字欄位防公式注入，支數增減保持數字，包含完整識別碼與方向矩陣。圖紙以編號與識別尾碼輔助追蹤。
