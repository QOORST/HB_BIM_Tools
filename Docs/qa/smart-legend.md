# HB 智慧圖例

## 用途與操作

入口：**HB_BIM Tools → 建模工具 → 標註工具 → 智慧圖例**。

將目前選取的模型構件，或目前模型視圖可見的構件，依型別去重後建立原生 Revit 圖例。提供圖例元件與型別文字；不以圖例列數當成模型數量。

1. 先準備一張原生 Revit 圖例作為範本，放入恰好一個圖例元件，設定所需比例與觀看方向。範本可含人工標題、線條等內容。
2. 切回模型視圖，選取構件（或使用目前視圖範圍），開啟智慧圖例。
3. 選範本、建立新圖例或更新既有 HB 圖例。勾選本次要保留的型別。
4. 設定名稱、文字型式、文字欄位、紙面 mm 的符號欄寬／文字寬／間距／最小列高。內建欄位：型別代碼、族群、型別、類別、說明；亦可輸入唯一的型別參數名稱。缺少或重名的自訂參數會停止，不會猜測。
5. 按「檢查並預覽」，檢查新增、更新、保留、移除及錯誤。不支援的型別需取消勾選或更換方向適用的範本後重新預覽。
6. 預覽通過後按「建立／更新」。任何設定變更都須重新預覽。
7. 可選既有圖紙配置，亦可先完成圖例，再用 Revit 手動放到多張圖紙。圖紙需有恰好一個圖框供範圍檢查。新配置放於圖框中央；已配置的視埠保留位置。

**更新以本次勾選的型別清單為準**，不自動追蹤上次來源視圖或新增構件。未勾選的舊列會在預覽標示移除。元件／文字的位置若經人工移動，更新會保留；但若因此重疊，整批停止，需先調整位置或版面。

## 實作與保護

- 不執行原始 Dynamo 圖，不需要 Data-Shapes、Clockwork、Genius Loci、archi-lab、Synthesize 或 IronPython 套件。
- 範本含詳圖複製；只將明確的種子元件替換成生成列。原範本不修改。
- 先實際複製圖例元件並設定型別，量測視圖中的顯示範圍。文字按紙面寬度換行，列高取符號與文字高度較大值並加入間距。
- 在目標視圖用獨立 Extensible Storage schema 記錄生成元件、文字、型別 UniqueId、內容與自動位置。同型別更新保留元素身分，不會每次刪光重建。
- 不清空視圖。非 HB 管理的人工內容不刪除；同名人工視圖不覆寫。刪除會連帶影響其他人工內容時回復整批。
- 人工改寫或刪除 HB 管理的文字、改變格式／型式／方向／引線、替換元件型別或改變視圖比例會停止更新。複製 HB 圖例後不能冒用原圖例的管理紀錄。
- 預覽執行相同 Revit 交易路徑，提交檢查後整個交易群組回復。正式執行失敗也回復整批，成功可一次 Revit Undo。
- 檢查所有配置該圖例的圖紙，包括未於本次指定的圖紙：圖例與視埠標題超框、與其他視埠或標題重疊即停止。圖框內部保留區、明細表、文字等仍需目視檢查。

## 第一版界線

- 類別是否支援取決於 Revit 原生圖例元件與範本觀看方向，不能保證任意族群均可生成；預覽列出失敗型別。
- 來源不含連結模型、不做跨專案合併、不自動新增原始圖例範本。
- 單列一個符號與一段欄位文字；尚無多欄分頁、表格框線、公司圖例範本庫、版本簽核或數量欄。
- 型別欄位的格式沿用 Revit 專案顯示單位；紙面版面計算以明確的 mm 換算，不解析中英文單位名稱。
- 不使用模型任意實例的外包框推算圖例尺寸。標準圖例元件本身無法表達的造型不改用不精確替代圖示。
- 範本人工內容的位置保留，但其與生成列的排版關係仍須人工安排。

## 驗收方式

- `Tests/SmartLegend.Tests`：離線規則驗收（空選取保護、身分去重、型別更名／規格變更、欄位驗證、排版與換行判定）。
- `Tests/SmartLegend.Native`：連結同一份正式原始碼，於獨立 Revit 2024 測試專案驗證預覽回復、建立、重跑、保護與圖紙配置。首次需建立原生圖例種子；後續可用已保存的測試範本重跑。測試啟動器只建立暫時 QA 外掛註冊，結束後需移除 `launch.json` 記錄的確切 manifest。
- Revit 2022／2024 分別建置；不可將 2024 原生結果推論為 2022、2025 或 2026 已實測。
