# 定位梁面歧義處理

- 自動管排與族中心定位共用判斷。只有同一梁、同一連結實例、同側法向且平面差不超過 0.5 mm 的有效候選會去重；不同梁不合併。
- 原搜尋距離規則內，優先使用涵蓋標註物件高程範圍的面。其餘保留原高程搜尋上限，不任意猜測最近樓層。
- 前兩名水平距離相差不超過 25 mm 時，列出梁 ID、距離、高程間距及面高程（模型座標沿視圖法向投影），提供手選候選面、略過、取消。
- 手選限已通過方向、範圍、高程、放置空間等檢查的歧義候選。實例及面參照均須吻合，不接受另一連結的同 ID 構件。
- 同一批後續項目仍包含已選歧義面時沿用；不保存到下次指令，不跨不合格候選使用。
- 不建立假參照或補畫線。尺寸仍經 Revit 原生參照、尺寸值與交易提交驗證，失敗不計成功。
