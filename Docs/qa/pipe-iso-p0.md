# 管路等角視圖 P0 修正與驗收

日期：2026-09-28。範圍：Revit 2024；已部署測試版、未提交 Git、未執行 Revit 實機驗收。

## 本次成果

- 工具列與視窗改稱「管路等角視圖」，移除標準施工／加工 ISO、尺寸標記等未實作承諾。
- PCF 預設不勾選，標示實驗性；未重做連通分析、加工幾何或驗證下游匯入。
- 各輸出逐項顯示成功、失敗、略過。單項失敗不阻擋其他輸出；移除命令層重複的全成功對話框。
- PNG 單選時自動建立視圖；明確指定 ExportRange.SetOfViews。視圖失敗時 PNG 顯示略過及原因。
- 部分成功保留成果；關閉視窗時不因 Cancelled 結果回復已完成視圖。重試會新增視圖／明細表及覆寫同名檔案，結果對話框明確提示。
- 一般視圖／CSV／明細表不再依賴舊路徑分析。分析器僅供實驗性 PCF 使用。
- ISOData 保存選定 SystemId，視圖與 BOM 直接從該系統取資料；系統不存在／為空時回報失敗。
- BOM 收集失敗不再偷偷改用可能漏件的路徑 BOM。
- DN25、25mm 與裸數字 25 都按 25 mm；只有明確英吋單位才換算，支援分數英吋。這是單位換算，不是 NPS 與 DN 對照表。
- 配件優先使用圓形管路接頭尺寸。多尺寸配件不再以第一個接頭代表全部；CSV 列出由大到小的接頭尺寸，這個順序不代表主管／支管拓樸。
- 材料讀取實例及類型的內建／中英文材料參數；缺值為「未指定」，不臆測 PVC／碳鋼。各別族群的自訂材料參數仍可能需要補對照。
- 管材數量單位為「段」，模型總長度另列 m；配件為「個」。CSV 使用 UTF-8 BOM、固定小數點並跳脫逗號、引號與換行。
- BOM 分組加入型別 ID、材料與配件各端尺寸，減少異型或異材質誤合併。
- 明細表按系統名稱精確相等篩選，再將實際元件 ID 集合與選定系統該類別元件比對。欄位不可用、篩選不符或交易未提交，兩張表一起回復；不留下未篩選的全專案明細表。
- 明細表僅管線與管配件，不含附件／設備；CSV 依 PipingNetwork 收集範圍可能較廣。介面及結果說明此差異，不宣称完整施工 BOM。
- 標籤族啟用與標註使用同一交易，直接指定族型別。任一管標註失敗則回復該次全部標籤，保留已完成視圖，回報失敗數及首筆原因，完整原因寫日誌。
