# 套管入口整理（2026-09-22）

- Ribbon 套管區：自動套管、套管管理、CAD 建立套管；分隔後保留建築開孔。
- 移除 GL 基準、GL 歸位的 Ribbon 入口，保留舊 command class 作相容用途，不刪除既有專案設定。
- 參數複製移至「族群／參數」，不變更授權與支援參數範圍。
- 管理更多選單：變更約束樓層、整理編號、刪除選取套管。
- 變更約束樓層使用管理清單選取項目，經 ExternalEvent 執行；當次明確選目標樓層，再確認預覽。不依賴舊 GL 設定，不改變自動建立的視圖規則。
- 歸位沿用原保護：目前只支援套管-圓形_無、兩端圓形接點、非群組／未釘住、可寫入樓層與立面高程；不能宣稱全部套管族通用。
- 取消選擇／預覽不修改模型；保留原實例、位置、方向、尺寸、接點與相依元素驗證。既有幾何操作策略未改動。
- 管理、CAD、開孔、參數複製採用不同既有圖示資源，不新增圖示相依。
