# 施工圖樣板管理

## 功能與操作

入口：HB 資料工具面板 → **施工圖樣板管理**。與 BIM 標準檢查使用相同的 Trial+ 權限。

1. 選擇系統用途。內建給排水、消防、套管定位、空調風管、空調水管、電力照明、弱電、特殊管路、綜合管線九個待設定項目；可新增任意系統／圖種／比例組合。內建名稱不是已完成的工程標準，仍須選取本專案的實際樣板及類型。
2. 在「編輯設定組合」指定專案既有視圖樣板，勾選允許的文字樣式、線性尺寸樣式、標籤族型；可選填須同張圖配置的圖例、明細表。
3. 填寫本版用途／變更說明並儲存。內容與版本紀錄存在模型的 Extensible Storage DataStorage，須正常儲存／同步 Revit 模型。
4. 選擇目前視圖／圖紙、事先選取的視圖／圖紙／視埠，或全部已上圖模型視圖；按「檢查／更新預覽」。支援平面、天花板平面、工程平面、剖面、立面。
5. 預設全部不勾選。依預覽勾選要處理的視圖；「勾選可套用項目」排除主從視圖與已有例外。跨用途視圖應分批處理，工具不依圖名猜測用途。
6. 要保留原樣板時，選取列 →「設定例外」→ 填理由 → 勾選並套用。只會登錄例外，不改該視圖樣板。清空理由再勾選套用即可解除例外。
7. 「套用勾選項目」指定視圖樣板並登錄版本；完成後重新檢查。整批使用一個 Revit 交易，失敗復原整批，成功可透過 Revit 復原。
8. 匯出 CSV 包含檢查結果、標準差異、版本說明及檢查範圍。尚未套用的例外原因明確標示為草稿。

## 既有樣板管理與新增

「視圖樣板…」開啟目前專案的非明細表視圖樣板清單：

- 顯示視圖類型、直接指定此樣板的視圖數、視圖名稱、圖號／圖名，未上圖視圖也會列出。
- 顯示目前引用此樣板的 HB 組合，包含草稿及停用組合。歷史版本仍保存在模型，但不當作目前引用列入。
- 「複製選取樣板」以既有 Revit 視圖樣板為來源新增，使用新的名稱及 UniqueId。
- 「從目前視圖建立」僅在 Revit API 認定目前視圖可建立樣板時啟用；建立前再次確認目前視圖身分。
- 新樣板不自動指派給任何視圖，也不自動替換組合的樣板；請返回「編輯設定組合」選用，再檢查／預覽／套用。
- Revit 名稱重複或建立失敗時整筆復原；不能覆蓋同名樣板。複製的篩選器、線型等參照內容仍可能共用，不能以使用視圖數推論共用內容的全部影響範圍。
- 此版沒有在 HB 直接修改既有樣板屬性、改名或刪除 Revit 樣板；修改屬性仍使用 Revit 原生介面。

「組合管理」管理的是 HB 設定組合，與 Revit 視圖樣板分開：

- 新增：輸入系統／圖種／比例名稱，開啟內容編輯器。
- 複製：沿用所選來源的類型選項作為草稿，版本從尚未設定開始，不複製視圖指派及例外。確認內容、儲存新版後才可套用。
- 重新命名：保留組合 Key、歷史版本名稱、視圖指派及例外。
- 停用：不刪除資料、不改視圖；停止編輯及套用。可勾「顯示停用組合」後重新啟用。
- 全部組合停用時顯示空清單與復原指引，不回退到其他預設或套用全部視圖。
- 組合名稱必填、最多 120 字，不得含控制字元；重名檢查包含停用項目並忽略前後空白及大小寫。

模型資料格式為 v2，可讀取第一版 v1 的三組設定並保留版本／例外。只有後續寫入交易才會存成 v2；舊版工具不支援 v2，不能降版覆寫。管理紀錄會保存新增、複製、改名及停用／啟用事件。

## 實際設定與保護

- 標準來源以 UniqueId 辨識，同名重建不會冒用原標準。
- 記錄類型參數原始值、尺寸格式、專案長度格式；不只檢查命名。
- 視圖樣板記錄參數、納管清單、分類可見性及覆寫、篩選器次序、條件、啟用／顯示及覆寫。
- 預覽發現來源設定異動／刪除會阻擋套用。先審查差異，再編輯並儲存新版才會接受新基準。
- 未更新視圖仍保留舊版本紀錄；新版本也會要求重新確認例外。
- 主從視圖不直接套用，避免影響未勾選的相依視圖；可登錄例外後由 Revit 原生工具處理。
- 套用前再次讀取來源和視圖，檢查版本及樣板 UniqueId，避免使用失效預覽。
- 模型有重複儲存區、重複版本／指派或不支援格式時拒絕寫入。

## 邊界

- 本版是目前專案內的樣板與設定組合管理，未提供跨 RVT／RTE 匯入、族群自動載入、RTE 產生或版本降轉。
- 套用只更改 ViewTemplateId 和 HB 紀錄。文字、尺寸、標籤的勾選清單是**允許類型檢查**，不會改寫既有標註，也不會覆蓋各 HB 工具的個人預設。
- 圖例／明細表檢查是確認指定視圖是否配置於同張圖紙，未自動配置，也未驗證內容與排版。
- 已存在視圖內的 TextNote、線性 Dimension、IndependentTag 會檢查類型；不判斷漏標、重疊或所有其他標註類別。
- 連結顯示、工作集、階段圖形、個別元素覆寫／隱藏、標籤族內文字與標籤設定仍需人工複核。類型參數相同不表示族內幾何／標籤內容相同。
- 通過檢查不代表施工圖可發行；套管位置、坡度、碰撞、數量完整性仍需對應工具與專業人員檢查。

## 驗證

自動測試：`Tests/DrawingStandards.Tests` 連結實際規則與 WinForms 原始碼，檢查實際值差異、刪除／同名重建、選取範圍、版本變更、例外、資料序列化、CSV 安全性、介面失效預覽及視窗尺寸。

Revit 原生驗收（尚未執行，不以離線測試取代）：

| 情境 | 預期結果 |
|---|---|
| 建立三組設定，儲存並重開模型 | 三組互不覆蓋，設定、版本與例外均保留 |
| 預覽 3 張視圖，只勾 1 張 | 只有該視圖指定樣板並寫入版本 |
| 相同名稱的文字／尺寸樣式改字高或精度 | 顯示實際值差異並阻擋套用 |
| 修改樣板篩選器數值、線寬、分類可見性 | 比對出變更；審查後儲存新版才能繼續 |
| 刪除標準類型再建立同名類型 | 判為原來源缺失；須在編輯器重選 |
| 專案例外／解除例外 | 前者不動 ViewTemplateId，後者指定樣板 |
| 主從視圖／主視圖含相依視圖 | 直接套用被阻擋，未勾選視圖不受影響 |
| 套用途中唯讀／工作共用權限失敗 | 整批復原，不留下成功版本紀錄 |
| 成功套用後使用 Revit 復原 | 視圖樣板及版本指派同時復原 |
| 目前圖紙、瀏覽器選取多張圖紙、選取視埠 | 範圍展開且去重；不含非支援視圖 |
| 圖例／一般明細表放入與移出同張圖紙 | 檢查結果隨實際配置改變 |
| 新版本與其他使用者重新開啟模型 | 可讀取模型內標準；舊版／例外明確提示 |
| 開啟第一版 v1 模型資料後新增自訂組合，再重開模型 | 舊版版本／例外保留，自訂組合不遺失、不重複加入內建項目 |
| 複製組合、改名、停用及重新啟用 | 組合與視圖樣板分開處理；停用不改視圖、複製不沿用指派 |
| 複製使用中的 Revit 視圖樣板 | 產生新的樣板，原有視圖及組合指派保持不變；使用數符合實際 |
| 從目前平面視圖建立樣板 | 新樣板出現在清單與編輯器，來源 ViewTemplateId 不變 |
| 目前為圖紙／不支援的視圖 | 從目前視圖建立按鈕停用，不回退使用其他視圖 |
| 名稱重複／Revit 拒絕名稱／權限不足 | 不新增半成品樣板，不覆蓋原樣板 |
| 建立或複製後使用 Revit 復原 | 新樣板被復原，原指派保持不變 |
