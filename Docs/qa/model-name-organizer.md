# 模型名稱整理：範圍與驗收

## 本次用途與操作

原「模型資料管理」改名為「模型名稱整理」，保留原命令類別與授權鍵。與「模型管理檢查」放在「模型管理」選單：檢查找問題，名稱整理負責預覽與修改。整理仍需 Standard／Professional 授權。

操作：選分類 → 搜尋並勾選 → 批次改名／直接編輯新名稱 → 套用勾選變更。

- 主視窗預設族群分類；取代文字與前後綴放入獨立小視窗，預覽只處理畫面勾選項目。
- 每次批次預覽從模型原名稱產生，重複操作不會累加前後綴；取代區分大小寫。直接編輯「新名稱」後仍需勾選才能套用。
- 其他篩選畫面的勾選項目不會被本次套用或刪除；其待套用預覽會在成功更新後保留。
- 顯示目前名稱、新名稱、分類、使用情況與狀態，完整分類／族群資訊在下方明細。
- 關閉、重新讀取或重新檢查時，若有未套用預覽會提示是否放棄。操作送入 Revit 後暫停介面，避免重複提交。
- 同一模型重複開啟會使用原視窗；文件已關閉、切到其他模型、唯讀或授權失效時不執行修改。

## 已涵蓋的名稱範圍

| 範圍 | 本次狀態 | 使用情況 |
| --- | --- | --- |
| 載入族群 | 保留 | 已放置實例數，不代表所有外部或預設參照 |
| 類型／系統類型／尺寸類型 | 保留 | 已放置實例數，其他參照未判定 |
| 一般視圖與明細表 | 保留並獨立分類 | 所在圖紙；未上圖紙不代表可刪除 |
| 材質 | 保留，統一用「材質」名稱 | 未判定，不以零使用假定 |
| 視圖樣板 | 新增 | 直接套用視圖數，其他參照未判定 |
| 參數與選取篩選器 | 新增 | 套用於視圖／樣板的數量；讀取不完整時明示 |
| 圖紙名稱 | 從視圖清單分出獨立分類 | 顯示圖號；只改名稱、不改圖號，允許不同圖紙使用相同名稱 |

排除專案瀏覽器、系統瀏覽器、內部視圖及圖框修訂明細表。可列出的內容仍可能受 Revit 編輯權限或原生名稱限制約束，無法寫入時整批回復。

## 與檢查串接

模型管理檢查的可整理結果提供「前往名稱整理」，帶入精確 UniqueId、勾選並篩選該項目。專案資訊等非名稱項目不提供此操作。

整理視窗內「重新檢查」沿用帶入時的檢查分類及命名規則，使用者仍按「開始檢查」執行。規則只在這次操作流程中保留，不存入模型；檢查略過原因仍僅限當次檢查視窗，不跨視窗保留。

既有名稱整理視窗有其他待套用預覽時，從檢查帶入新項目會保留那些預覽。重新檢查前則需確認放棄未套用預覽。

## 修改與刪除保護

- 套用前以模型最新內容重新檢查空白、非法字元、命名範圍重複、元素是否仍存在及原名稱是否改變；確認預覽後再檢查一次。
- 同一批次先使用唯一暫存名稱，再套用最終名稱，支援 A／B 名稱互換。所有操作在單一交易內；失敗回復整批。
- 只有 `TransactionStatus.Committed` 才回報成功；原生錯誤透過失敗處理要求回復。
- 刪除移至「更多」。先在交易內呼叫 Revit 刪除取得完整回傳元素集合，回復交易，再列出勾選及連帶刪除的所有元素供確認。
- 刪除影響包含目前作用中視圖時停止。正式刪除前核對元素身分與名稱，刪除後核對影響集合必須與預演一致，否則回復。
- 不以實例數量作為可刪除判定，不提供自動清除全部未使用內容。

## 後續擴充評估

| 候選 | 建議 | 原因／前提 |
| --- | --- | --- |
| 常用命名方案儲存 | 下一階段優先 | 可減少重複輸入；先以「取代／前後綴」小方案為限，不引入大型規則引擎 |
| 線型、填滿樣式名稱 | 後續評估 | 與施工圖表現有關，但須另查各項 API 寫入能力及使用位置，不能直接套用目前通用名稱路徑 |
| 樓層、軸網名稱 | 獨立規劃 | 涉及視圖命名及專案協調；需專用預覽及既有編號工具分工，避免一般改名順便變更 |
| 圖紙圖號／視圖編號 | 獨立工具 | 有唯一性、排序與出圖編碼需求；本功能只改圖紙名稱 |
| 設備編號、備註、規格等參數 | 另設參數批次編輯 | 需要型別／實例、唯讀與資料型態處理，混入此視窗會增加操作負擔 |
| 實際 MEP 系統實例名稱 | 後續評估 | 目前支援系統類型名稱；系統實例需另驗證連接與自動產生命名行為 |
| 連結模型內的名稱 | 不直接修改 | 目前只整理作用中模型；來源檔由其負責人開啟後整理 |

### 原生驗收待辦

1. 在模型副本測試七類名稱；視圖樣板、兩類篩選器、明細表與圖紙須各含至少一筆。
2. 驗證同類型命名範圍限制、互換名稱、讀取後外部改名、不可編輯元素與工作共享權限；確認交易失敗無暫存名稱殘留。
3. 比對族群／類型實例數、視圖與明細表上圖紙、直接視圖樣板及篩選器參照；驗證資料量大的模型可接受的等待時間。
4. 於副本刪除有實例的族群／類型及含標註的視圖，比對預演連帶清單、取消後元素完整性、正式提交／取消原生失敗提示與 Revit 復原。
5. 從檢查帶入、修改、重新檢查，確認規則沿用；切換文件、重複開啟與未套用預覽保留流程。
6. 改名已被施工圖組合引用的樣板／類型後，檢查其設定快照與引用是否需重新確認／儲存新版。
7. 確認 Ribbon「模型管理」兩個入口、125%／150% DPI，與長名稱的完整閱讀。
