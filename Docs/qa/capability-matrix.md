## 證據與解讀

- `YD_RevitTools.LicenseManager.csproj`：四年版條件編譯與排除清單。2025/2026
  雖關閉 UseWPF，主專案仍為 net48；不能因此宣稱完成較新 Revit 主機的 .NET
  遷移或載入相容性。需各年版實際建置及啟動證據。
- `App.cs`：房間裝修使用 `!REVIT2025`；族滑桿／族型資訊使用
  `!REVIT2025 && !REVIT2026`；`AddMEPToolButtons` 先呼叫優化入口後 return，
  後方舊 AutoPipeRouting／PipeToISO 按鈕碼不是目前可見入口。
- 公司族庫是另一專案；其 DLL 與 SQLite 資料庫存在才建立入口。
  主專案單獨可建置不代表完整安裝套件已具備公司族庫。
- 「存在」只表示來源或入口存在，並不保證幾何、交易、匯出、取消或回復行為正確。

## 尚待實機覆核的重點

各年版各自記錄成功、失敗、略過及原因；不可把 2024 結果擴張成四年版通過。

- 啟動／授權／選單載入與公司族庫依賴載入。
- 牆板分割：失敗或取消不刪原件；成功後屬性、約束、接合及單次復原。
- MEP 避碰／重建：連接、尺寸／型別、完整交易回復、短管與不支援案例。
- 房間裝修（2025 不適用）、模板、樓梯、套管年版族群載入。
- 連結尺寸／梁面候選、DC3D 預覽、取消與跨文件保護。
- COBie／Excel／簡報匯出、SQLite 讀寫、缺失依賴時錯誤回報。
- 乾淨機安裝、升級、解除安裝、簽章及憑證流程。
