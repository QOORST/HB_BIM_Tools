# 套管管理與更新預覽介面（2026-09-22）

## 本次變更
- 管理頁範圍與自動檢查狀態分開；檢查狀態不代表套管都正常。
- 管理明細可拖曳分隔線調整高度，也可取消「顯示明細」收起。
- 定位／重新檢查／整理編號與更新／刪除／關閉分組，刪除以次要文字樣式呈現，原確認流程保留。
- 管理欄位支援換行；一般來源位置偏移顯示實際毫米值，缺少定位資料顯示原因。
- 更新預覽精簡四欄：編號、檢查結果、差異摘要、處理方式。
- 下方唯讀明細列出 ID、中心位移、原／新長度、原／新立面高程、原／新樓層及完整原因，可拖曳高度並捲動。
- 比對位移、長度及立面高程，已取得差異大於 0.5 mm 顯示「可更新」，其餘可執行項目顯示「可同步」。此為摘要顯示門檻，不改變原更新精度與交易行為。
- 未取得值顯示「未取得」。方向及其他參數尚未完整比對，不能宣稱「無需更新」，可同步仍可能寫入模型。
- 有待確認項目仍阻擋整批確認更新，不自動略過或刪除。
