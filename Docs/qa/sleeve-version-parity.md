# 自動套管跨版本驗收

## 共用規則
- 2024 使用 WPF；2025/2026 使用 WinForms。介面可以不同，處理規則不得各自複製維護。
- 預設族群由 SleeveFamilyCatalog.LoadMissing 統一處理；設定頁列舉族型前先補載缺少的族群。
- 使用安裝位置 Resources/Families，不依賴特定公司的網路磁碟。缺檔、族群名稱不符或版本不相容須顯示原因。
- 既有同名族群及既有共用族群不自動覆寫。新版接點須由使用者明確重新載入；取消設定視窗不會移除已補載的族群。
- 兩版設定選單共用 SleeveFamilyCatalog.IsSleeveSymbol，管徑共用 PipeSleeveNominalRules，預設與儲存共用 PipeSleeveSettingsStore。
- 目前視圖限制預設開啟，兩版均可調整、儲存和還原。
- 管徑進階區預設收合；收合不可清除設定或關閉管徑對應功能。

## 必跑檢查
1. 執行 Tools/QA/Test-SleeveParity.ps1 -Repo <專案根目錄>，驗證共用入口與保護規則未分岔。
2. 分別編譯 Release2024、Release2025、Release2026，記錄警告與錯誤；編譯不等於可上線。
3. WPF 與 WinForms 於 800/1240 寬、100%/125%/150% DPI 驗證收合、展開、捲動、頁尾按鈕與完整說明文字。
4. 空白模型：開啟設定前應載入預設族群。已載入模型：不改族型參數、尺寸、接點與標註。
5. 缺檔與較新版 RFA：明確提示，不崩潰；可繼續選用模型既有族型。
6. 在兩版往返儲存模型來源、樓層、管徑清單、族型、更新、編號、目前視圖限制，確認值一致。
7. 新版族群以測試模型驗證旋轉、鏡射、方向標註及更新後標註參照。
