# HB_BIM Tools 文件整理紀錄

本專案過去曾保留多份舊版安裝、部署、發佈、功能測試與修復報告於 `Docs/Archive/`。這些文件多為階段性紀錄，內容已由目前的 README、CHANGELOG、建置說明、部署指南與功能手冊取代。

## 目前保留的主要文件

- `README.md`：專案總覽與使用入口。
- `Docs/BUILD_INSTRUCTIONS.md`：建置與編譯流程。
- `Docs/CHANGELOG.md`：版本更新紀錄。
- `Docs/手動部署指南.md`：使用者端部署流程。
- `Docs/授權管理使用說明.md`：授權產生與管理方式。
- `Docs/部署方案總結.md`：目前部署策略。
- 主要功能手冊：對齊牆輪廓、管線套管等現行功能文件。

## 已移除的封存類型

- 舊版安裝檔更新報告。
- 舊版發佈說明與檢查清單。
- 一次性問題修正報告。
- 舊版快速部署說明。
- 已由現行文件取代的 HTML 入口與舊手冊。

若未來需要保留大量歷史文件，建議放在 GitHub Release、外部文件庫或壓縮備份，不再放入主要原始碼樹。
