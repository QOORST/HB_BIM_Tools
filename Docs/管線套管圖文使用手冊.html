Pipe Sleeve 自動套管圖文使用手冊

HB_BIM Tools v2.5.10｜適用 Revit 2022 / 2024 / 2025 / 2026
用途：當 Pipe、Duct、電管或電纜線架穿越牆、樓板、梁時，自動建立圓形套管或矩形開孔；可處理目前模型與 Revit 連結模型，並可在管線改路徑後更新既有套管。

1. 操作流程

  1. 在模型中選取要處理的 Pipe 或 Duct。
  2. 執行 HB_BIM Tools → MEP 工具 → Pipe Sleeve。
  3. 確認套管族型、DN 對應與間隙距離。
  4. 選擇分析目前模型、連結模型，或兩者皆分析。
  5. 按 分析 確認穿越點數量。
  6. 按 開始執行 建立或更新套管。
  7. 豎井或樓板大開口內的立管，若沒有與原生樓板實體產生交段，不會生成穿樓板套管；勾選更新現有套管重新執行時，會清理目前視圖範圍內同來源的舊版殘留套管。
建議先框選局部管線測試，確認專案座標與連結模型位置正確後再放大範圍。

2. 目前視圖範圍與範圍框

規則

Revit 選取管線時會選到整個元素，不是只選畫面中可見的線段。Pipe Sleeve 會以目前作用中視圖限制生成範圍：3D 視圖使用 Section Box，平面/立面/剖面使用啟用中的 CropBox。

  • 交點在目前視圖範圍內：建立或更新套管。
  • 交點在範圍框外：略過，不生成套管。
  • 套管管理預設只列目前視圖內、自動生成且含來源管線 ID 的套管。

測試局部區域時，請先確認 3D 視圖的範圍框已啟用且包住本次要處理的管線與建築構件。

即使選到的是同一整條管線，工具只會處理目前視圖範圍內的穿越交點。

3. 穿牆套管

牆管線套管

規則

穿牆時，工具會先找管線穿越牆厚範圍，再把套管中心修正到牆中心線。套管方向使用牆的法線方向，因此會垂直於牆面，不會跟著斜管歪斜。

項目判斷方式
中心點管線穿越牆後，投影到牆中心線
方向垂直牆面
長度依牆厚

4. 穿樓板套管

規則

穿樓板時，套管中心取管線穿越樓板厚度的中點。先前已調整為不再用整個樓板 bounding box 中心，避免立管套管被樓板增築層拉偏。

項目判斷方式
中心點管線穿越樓板厚度的中點
方向垂直樓板面
長度依樓板厚

5. 穿梁套管

穿梁時，套管長度通常涵蓋梁增築/增打寬度，因此梁不套用增築排除規則。

規則

穿梁套管目前改用梁中心線推算側面垂直方向，不沿管線方向旋轉。這樣在立面看會更接近現場預留套管做法。

項目判斷方式
中心點管線穿越後修正到梁中心位置附近
方向垂直梁側面
長度涵蓋梁寬，含梁增築/增打

6. 更新既有套管

管線調整路徑後，不需要刪除舊套管。重新選取管線並勾選 更新現有套管，工具會用 來源管線Id 找回既有套管。

  • 找到既有套管：移動、旋轉並更新尺寸/長度/備註。
  • 找不到既有套管：建立新套管。
  • 建立或更新完成後，若啟用自動編號，會依樓層、系統、穿越類型、DN 與元件 Id 整理目前視圖範圍內的自動套管編號；完成通知以整理後範圍總數為準。

7. 建議檢查項目

穿梁套管若判定為需結構確認或高風險，仍會正常生成，但會在目前視圖以紅色覆寫顯示；提醒等級以橘色提示。分類包含孔徑、梁深 1/3、梁端/柱邊 2H、同梁孔距 3D/300mm，方便後續在套管管理中篩選。套管設定介面也已加入穿梁原則示意圖，執行前可直接對照禁開區與風險分類。

測試時建議用 6 種情境確認：3D 範圍框局部生成、水平管穿牆、立管穿樓板、水平管穿梁、矩形風管穿牆、管線改路徑後勾選更新既有套管。

建築模型端開孔同步

建議工作流

  1. MEP 模型先用 Pipe Sleeve 產生套管需求。
  2. 建築模型連結 MEP 模型，並以 3D 範圍框限制同步區域。
  3. 建築模型載入獨立切割族：套管-開口圓形_無、套管-開口矩形_無 或 開孔-開口矩形_無。
  4. 執行 建築開孔，由連結 MEP 套管建立或更新建築端開孔/預留洞。

建築開孔同步不混用 MEP 套管族。開口族可使用管附件類別，工具以名稱中的開口/開孔與圓形/矩形辨識；族型可依來源套管的 DN、標稱直徑或尺寸參數自動匹配。缺少切割族時會提示，不會用一般套管代替。 Pipe Sleeve 新增止水套管類型相容；自動大一級預設仍優先套用一般套管，止水套管保留手動選用。

重跑同步時，以連結實例與來源套管 UniqueId 對應既有開孔，避免同一來源重複建立。
