## 1. 功能目的

`Pipe Sleeve` 用於管線、風管、電管或電纜線架穿越建築構件時，自動建立套管或矩形開孔。

目前支援：

- Pipe 圓管穿牆、穿樓板、穿梁
- Duct 圓形風管穿牆、穿樓板、穿梁
- Duct 矩形風管穿牆、穿樓板、穿梁，使用矩形開孔族群
- 電管 Conduit 穿牆、穿樓板、穿梁，使用圓形套管族群
- 電纜線架 Cable Tray 穿牆、穿樓板、穿梁，使用矩形開孔族群
- 建築構件可來自目前模型或 Revit 連結模型`r`n- 建築模型端可讀取連結 MEP 模型的自動套管，建立獨立開孔/預留洞切割族

在 Revit Ribbon 中開啟：

`HB_BIM Tools` → `MEP 工具` → `Pipe Sleeve`

目前 MEP 工具面板正式保留：

- 支管對齊
- 批次對齊
- 手動翻彎
- Pipe Sleeve

## 3. 使用前準備

### 3.1 預設套管族群

安裝檔已附帶預設族群，其他電腦安裝後不需先手動準備族群：

- 圓形套管：`套管-圓形_無.rfa`
- 矩形開孔：`開孔-矩形_無.rfa`

工具啟動時會先檢查專案內已載入的族群；若專案尚未載入，會從本機外掛安裝目錄 `Resources\Families` 自動載入。`套管-圓形_無` 會比對族型參數 `HB_族群版本`，目前內建版本為 `2026.09.08.01`；若專案內同名族群沒有版本或版本較舊，工具會載入內建新版並覆蓋，版本相同則跳過載入以避免卡頓。只有本機資源缺失時，才會回退到公司網路族庫路徑。

族群載入已在套管服務層保底處理；快速執行流程與設定視窗流程都會先確認預設套管族群。Revit 2024 設定視窗在載入族群後也會立即再生模型，避免第一次執行時因族群或幾何尚未穩定而需要重複執行。

### 3.2 建議選取管線後再執行

可先在模型中選取要處理的 Pipe / Duct，再按 `Pipe Sleeve`。

若未選取，工具會要求重新手動選取管線。

## 4. 基本操作流程

1. 選取要處理的 Pipe 或 Duct。
2. 點選 `Pipe Sleeve`。
3. 確認套管類型與尺寸設定。
4. 選擇穿越位置來源：
   - 目前模型
   - 連結模型
5. 設定間隙距離。
6. 確認是否勾選 `更新現有套管`。
7. 按 `分析` 查看預覽資訊。
8. 按 `開始執行` 建立或更新套管。

---
## 4.1 目前視圖範圍與範圍框

工具會以「目前作用中視圖」作為生成範圍限制。

在 3D 視圖中，若已啟用範圍框 / Section Box，只有交點位於範圍框內才會建立或更新套管。這可避免選到一整條跨越多區域的管線時，工具沿整條 `LocationCurve` 在全模型其他位置生成套管。

實務建議：

- 使用 3D 工作視圖時，先打開並調整範圍框，只框住本次要處理的區域。
- 選取管線後執行 Pipe Sleeve；即使 Revit 選到的是整條管線，工具只會處理目前視圖範圍內的穿越交點。
- 套管管理介面預設也只列出目前視圖內、自動生成且含 `來源管線Id` 的套管；需要全模型檢視時再切換範圍。
- 豎井或樓板大開口內的立管，若沒有與原生樓板實體產生交段，不會生成穿樓板套管；重新執行且勾選更新現有套管時，會清理目前視圖範圍內同來源的舊版殘留套管。
- 若視圖沒有啟用 Section Box / CropBox，工具無法可靠取得畫面可見範圍，會退回依選取管線完整元素分析。

## 5. 套管尺寸設定

### 5.1 依管徑自動套用大一級

預設會依管線標稱直徑 DN 自動套用大一級套管類型。

範例：

| 管道標稱直徑 | 預設套管類型 |
|---|---|
| DN15 | 25mm 套管 |
| DN20 | 25mm 套管 |
| DN25 | 50mm 套管 |
| DN32 | 50mm 套管 |
| DN40 | 50mm 套管 |
| DN50 | 80mm 套管 |
| DN65 | 80mm 套管 |
| DN80 | 100mm 套管 |
| DN100 | 125mm 套管 |
| DN125 | 150mm 套管 |
| DN150 | 200mm 套管 |
| DN200 | 250mm 套管 |

實際清單會依目前模型已載入的套管族型顯示。新增的止水套管類型會保留在下拉清單中供特殊需求手動選用；預設「管徑放大一級」規則會優先套用一般套管。

### 5.2 矩形風管開孔

矩形風管使用 `開孔-矩形_無`。

矩形開孔供矩形風管與電纜線架使用，不會套用到 Pipe、電管或圓形風管。

## 6. 中心點、方向與長度規則

### 6.1 套管中心點

套管中心點不是只取建築構件表面的一個交點，而是以管線穿越建築構件厚度範圍後的中心位置為基準。

- 穿牆：中心點落在牆中心線附近
- 穿樓板：中心點取管線穿越樓板厚度的中點
- 穿梁：中心點落在梁中心位置附近

### 6.2 套管方向

套管方向以建築構件立面為準，不直接跟著管線斜角。

- 穿牆：垂直於牆面
- 穿梁：垂直於梁側面
- 穿樓板：垂直於樓板面

這比較符合一般套管圖與現場預留套管作業邏輯。

### 6.3 套管長度

套管長度依建築構件判斷：

- 穿牆：依牆厚
- 穿樓板：依樓板厚
- 穿梁：依梁寬或穿越梁的有效寬度

若建築構件來自連結模型，會套用連結模型座標轉換後再判斷位置與方向。

---

## 7. 增築/增打邊界判斷

工具提供 `排除牆/樓板增築邊界` 選項。

建議預設開啟。

目前規則：

- 牆：可排除增築/增打構件，避免套管中心被非主體牆層拉偏
- 樓板：可排除增築/增打構件，避免立管穿樓板位置跑掉
- 梁：穿梁套管通常需要涵蓋梁增築寬度，因此不排除梁增築寬度

---

## 8. 更新現有套管

管線路徑調整後，可以直接更新既有套管。

操作方式：

1. 選取調整後的管線。
2. 開啟 `Pipe Sleeve`。
3. 勾選 `更新現有套管`。
4. 按 `分析`。
5. 按 `開始執行`。

更新時會依既有套管的 `來源管線Id` 找回對應套管，並更新：

- 套管中心位置
- 套管方向
- 套管長度
- 套管直徑或矩形開孔寬高
- 備註：穿牆 / 穿樓板 / 穿梁
- 來源模型：目前模型 / 連結模型
- 來源管線 Id

建立或更新套管完成後，若啟用自動編號，工具會立即依「樓層 → 系統 → 穿越類型 → DN → 元件 Id」整理目前視圖範圍內、且含 `來源管線Id` 的自動生成套管編號。完成通知會顯示整理後的套管總數，避免整理前暫時編號與管理清單不一致。

若找不到對應既有套管，工具會建立新的套管。

---

## 9. 重複放置判斷

未勾選 `更新現有套管` 時，工具會檢查穿越點附近是否已有套管。

若附近已有來源相同或未標記來源的套管，會略過建立，避免重複放置。

---

## 10. 自動寫入參數

工具會嘗試寫入下列參數，實際可寫入項目依族群參數而定：

- 套管編號 / Mark
- 套管直徑 / Diameter / Diatot / 邊界寬度
- 管徑 / Pipe Diameter
- 套管長度 / 長度 / Length / Depth
- 穿越厚度 / Host Thickness
- 備註 / Comments
- 穿越構件：穿牆 / 穿樓板 / 穿梁
- 穿越來源：目前模型 / 連結模型
- 管道標稱直徑：DNxx
- 來源管線Id

## 11. 建築模型端開孔同步（第一階段）

當機電與建築模型皆由內部人員建置，建議工作流如下：

1. MEP 模型先用 Pipe Sleeve 產生套管需求，並確認套管編號、樓層、系統、穿越構件與來源管線 Id 正確。
2. 建築模型連結 MEP 模型。
3. 建築模型載入或放入獨立切割族群，不混用 MEP 套管族：
   - 圓形開孔：套管-開口圓形_無.rfa
   - 矩形開孔：套管-開口矩形_無.rfa / 開孔-開口矩形_無.rfa
4. 在建築模型中使用 3D 視圖範圍框限制本次同步區域。
5. 執行 建築開孔，工具會讀取連結 MEP 模型內含 來源管線Id 的自動套管，建立或更新建築端開孔/預留洞。

建築端開孔同步使用「連結實例 Id + 來源套管 UniqueId」做對應鍵；重跑時會更新既有開孔位置、方向、尺寸與備註，不會因同一個來源套管重複建置。若 MEP 端刪除或重建套管，建築端需重新同步並檢查管理清單。

### 11.1 開孔族型自動匹配

建築端不需要另外建立 DN 對應表。工具會掃描同形狀的開孔族型，依下列順序自動挑選：

1. 族型或族群名稱包含 DN100、100A、100mm 等尺寸文字。
2. 族型參數包含 管道標稱直徑、標稱直徑、開孔直徑、直徑、Diatot、寬度 等尺寸值。
3. 找不到精準匹配時，退回同形狀第一個可用開孔族型。

建議族型命名仍保持清楚，例如 套管-開口圓形_無: 套管-100A 或 套管-開口矩形_無: 300x200，方便人工檢視與明細統計。

### 11.2 注意事項

- 建築開孔族可使用「管附件」或一般模型等可放置族群，工具以族群/類型名稱辨識開口形狀；名稱需含「開口」或「開孔」，並含「圓形」或「矩形」。若族群本身沒有 Void/Cut 行為，工具只會放置開孔標示元件，不會真正切割構件。
- IFC 連結若在 Revit 中可被辨識為牆、樓板、梁幾何，MEP 端套管判斷可支援；建築端開孔同步第一階段讀的是連結 MEP 模型內已生成的套管，因此重點是 MEP 套管本身需先正確產出。
- 若缺少 套管-開口圓形_無.rfa 或 套管-開口矩形_無.rfa / 開孔-開口矩形_無.rfa，工具會提示缺少開孔/預留洞切割族型，不會使用一般 套管-圓形_無 代替。
## 12. 常見問題

### Q1. 為什麼套管沒有沿著斜管方向？

目前工具採用實務常見邏輯：套管垂直於建築構件立面，而不是沿管線斜角。穿牆、穿梁、穿樓板都以構件面向為準。

### Q2. 為什麼穿梁套管長度會比梁本體寬？

穿梁時通常要涵蓋梁增築或增打寬度，因此梁不套用增築排除規則。

### Q3. 管線移動後，套管可以跟著更新嗎？

可以。重新選取管線，勾選 `更新現有套管` 後執行，工具會依 `來源管線Id` 更新既有套管位置、方向與尺寸。

### Q4. 為什麼找不到套管類型？

請確認安裝目錄 `Resources\\Families` 內含預設族群，或模型中已載入名稱包含 `套管` 的族型。本機資源缺失時，工具才會改用公司網路族庫路徑。

### Q5. 為什麼矩形開孔沒有出現在圓管選項？

矩形開孔族群供矩形風管與電纜線架使用；圓管、電管與圓形風管會使用圓形套管。


### Q6. 我只選取目前視圖中的管線，為什麼以前會生成到全模型其他位置？

Revit 的選取是選到整個元素，不是只選視圖中看得到的線段。若一條管線跨出目前工作區，舊版會沿整條管線分析，因此可能在範圍外也建立套管。

目前版本已改為：建立候選交點前先檢查目前作用中視圖的 3D Section Box 或 CropBox，只有範圍內的交點才會生成或更新。測試時請確認目前 3D 視圖的範圍框已啟用且大小正確。

## 13. 建議測試流程

每次更新工具後，建議用以下模型情境快速驗證：

1. 水平管穿牆：確認套管中心在牆中心，方向垂直牆面。
2. 立管穿樓板：確認套管中心不被樓板增築層拉偏。
3. 水平管穿梁：確認套管方向垂直梁側面，長度涵蓋梁寬。
4. 管線改路徑後重跑：勾選 `更新現有套管`，確認既有套管移動而非重複新增。
5. 矩形風管/電纜線架穿牆：確認使用矩形開孔族群；電管確認使用圓形套管。

---

## 13. 注意事項

- 建議在 3D 視圖或清楚的工作視圖中先選取要處理的管線。
- 大型模型建議先框選局部範圍的管線再執行，避免分析過多元素。
- 若 Revit 連結模型有旋轉或位移，工具會轉換座標後判斷，但仍建議先用少量管線測試確認專案座標設定正確。
- 若套管族群的方向參考與預期不同，可能需要調整族群本身的 Facing Orientation 或參考平面設定。

## 14. 穿梁第一階段檢核

第一階段採用「提示、備註與顏色分類」方式，不會阻擋套管建立。

套管設定介面右側提供「穿梁原則示意」範例圖，可快速對照紅色高風險、橘色提醒與正常分類。

目前會檢核：

- 孔徑提醒：套管/開孔直徑大於等於 100 mm 時，標記為 `提醒`，目前視圖以橘色提示
- 大孔提醒：套管/開孔直徑大於等於 200 mm 時，標記為 `需結構確認`，目前視圖以紅色標示
- 梁深比例：孔徑大於梁深 1/3 時，標記為 `高風險`
- 梁端/柱邊距離：套管中心距梁端小於 `2H` 時，標記為 `高風險`，目前視圖以紅色標示
- 同梁孔距：同一支梁上孔距小於 `3D` 或 `300 mm` 時，標記為 `需結構確認`

工具會寫入：

- `備註`：補充穿梁檢核內容
- `穿梁風險等級` / `Beam Opening Risk`
- `穿梁檢核` / `Beam Opening Check`

梁端/柱邊 `2H` 已納入第一階段分類；此判斷以梁 LocationCurve 端點推估梁端，若模型梁為跨多柱連續建模，仍建議由結構人員複核。
## 15. 樓層基準與高程

套管建立或更新後，工具會依套管中心點 Z 值判斷所屬樓層：

- 優先選擇「不高於套管中心」的最近樓層作為基準樓層。
- `距離樓層的高程` 會寫入：套管中心高程 - 基準樓層高程。
- 例如 FL2 = 4000 mm、FL3 = 8000 mm，套管中心高程 7592.9 mm 時，基準樓層為 FL2，offset 約 3592.9 mm。

這樣剖面/標註可依當層顯示 BOP/TOP 或中心高程，不會全部從 1FL 累計。
